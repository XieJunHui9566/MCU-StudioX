# 自定义 UI 与扫描诊断验收

证据输出限定在 `artifacts/validation/lvgl-custom-ui-current`，不连接硬件，不下载固件。
外部授权边界使用系统 Temp 下精确命名的 `StudioXLvglCustomUiExternal` 小标记目录，运行结束核对绝对路径与重解析点后清理。
扫描测试使用少量标记文件，标记库明确不用于编译；真实窗口复用已有共享 LVGL 与内置 PC 工具链。

## 发现与检查

- 库根目录可位于三层目录下，名字与 LVGL 不同；扫描依据内容识别。
- 同一工程包含两个有效版本候选时，保留各自版本与根目录供明确选择，不静默挑一个。
- LVGL 8.3 与 9 的候选同时发现；9 应明确标记不支持，不能使用 8.3 端口启动。
- 缺少核心源文件、把公共库核心源重复列入 UI、把库 `src` 作为另一个 UI 根或混入另一版本的 include 都必须诊断。
- 工程入口缺失、MCU GPIO/启动依赖、资源目录缺失提供可操作说明，不宣称检查成功。

## 配置与 MCP

- 通过真实 MCP 握手发现 discovery / inspect / configure。
- discovery / inspect 只读且不请求写授权；configure 遵循写授权与编辑器未保存保护。
- 拒绝或未保存时不改配置文件；成功保存的库、源、头文件、资源路径均可相对解析。
- 多个候选明确选择；未支持版本和有错误的配置不能持久化为可运行配置。
- 未授权外部绝对目录拒绝扫描；授权后跨盘目录能被发现，并说明相对配置需要同盘导入。

## 真实自定义窗口

- C dashboard、C++ details 页面、独立 C 图片文件参与同一构建；实际验证 `lvgl.h` 与 `lvgl/lvgl.h` 两种 include。
- 截图验证首页背景与图片像素；真实 pointer 点击切页后验证第二页颜色，避免仅查看工具返回的成功文本。
- 新工程没有 MCU 构建结果时，目标 Flash/RAM 保持未知；未标定传输带宽时 MCU 传输上限保持未知。
- 修改运行时资源触发自动重建并改变实际像素；之后错误映射不能替换运行窗口的旧资源，仍能截图。
- 停止后回收两个当前资源 slot 与 staging，不保留每次资源复制的历史。
- 保留截图、诊断与小型 fixture，复用单一 `.build/pc-preview`；不重复复制 LVGL 或数百 MiB 工具链。
