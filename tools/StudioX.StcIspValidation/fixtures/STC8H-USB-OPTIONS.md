# F784 USB 选项离线夹具

`stc8h-usb-options.json` 的 28 个完整配置包由官方 AiCube-ISP v6.97C 的原始 x86 选项编码器在 Unicorn 中执行产生，不能标记为新的实板抓包。官方 PE 不随仓库分发。来源 SHA-256、函数地址、准确目标和 16 个状态说明分支保存在 JSON 中；芯片电气效果和新字段持久化尚待单项实板验证。

复现使用已有官方 PE 与隔离的 `unicorn==2.1.4`、`pefile==2024.8.26`，不安装全局包、不启动官方工具，不加载 Windows/设备 API：

```text
python tools/Research-StcUsbOptions.py <AiCube-v6.97C.exe> <新输出目录> <隔离依赖目录>
```

脚本核对 PE 指纹和准确型号描述表，执行范围限制为原编码函数、状态回映及选定的纯状态解释代码。只有文字查找/日志出口以空实现替换；任何其它执行地址失败。编码器的基准完整命令先与此前官方 24 MHz 抓包比对，再穷举 1280 个内部配置字节值并生成单选项向量。另执行官方写入后的状态回映逻辑，穷举 1280 个命令字节值，防止把 C40 误作 EEPROM / 下载条件字节（实际为 C37）。不会打开设备或调用擦写。

生产实现独立写在 C# 中，不依赖 Unicorn、官方 EXE、Windows 注册表或外部安装。`StudioX.StcIspValidation --usb` 执行完整报文对照，并穷举 7168 组原始字节与合法设置组合，确保未指定位、校准和保留区不变。不兼容分区、未知 ROM、非法值与尚未接入字段均必须在擦除前拒绝。

当前仅 STC8H8K64U / F784 / ISP 7.4.12U 使用此布局。复位脚位极性与串口参考类不同，不允许把本夹具推广到其它 STC8、STC32 或其它 ROM。EEPROM 下次擦除选项与本次擦除策略、全区填充及分区为不同功能。
