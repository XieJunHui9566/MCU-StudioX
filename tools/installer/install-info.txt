MCU StudioX · 独立单片机开发环境

适用于 Windows 10 / Windows 11 64 位。
包含 .NET 桌面运行时、ARM GCC、RISC-V GCC、AGM AgRV 工具链、OpenOCD、CMake、Ninja、clangd 和 Git，无需另外配置 PATH 或安装 VS Code 插件。

安装程序可选择安装位置，只为当前 Windows 用户安装。
完整安装约占用 6.5 GB 磁盘空间；安装时还需要一定临时空间。

升级方法
先保存工程并关闭 MCU StudioX，再运行新版安装包，使用原目录覆盖升级。
可运行同版本安装包修复程序文件。安装程序会拒绝覆盖更高版本。
工程、个人设置、背景配置和已导入器件包保存在安装目录外，升级和卸载不会主动清除这些数据。

器件包
安装目录中的 device-packs 文件夹提供当前附带的 .mcupack 文件。
也可通过开始菜单“MCU StudioX → 器件包”找到，再在 IDE 内导入。

本版本为预览版，提供源码/反汇编调试、FreeRTOS 状态与 MCP、AI 助手、串口终端、协议解析、串口绘图和工程终端；具体支持范围见使用说明。
