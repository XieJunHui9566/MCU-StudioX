MCU StudioX · 轻量版

适用于 Windows 10 / Windows 11 64 位。
包含自包含 IDE、语言服务、Git、器件包、内置插件与完整功能入口。
此安装包不附带开发工具链。

选择器件和模板创建工程后，进入“工具 → 准备工程工具”，导入所需版本的 .mcutoolchain。
无需修改系统 PATH 或安装全局 Python。组件版本由工程声明，缺少组件会显示明确提示。

完整包和轻量包使用同一个产品身份，可在原目录相互覆盖安装。
已有开发组件整目录保留，不自动覆盖、升级或降级；组件修复使用 IDE 内的校验与离线修复入口。
卸载 IDE 也保留开发组件、用户数据和工程。旧安装目录中已取消的程序文件不会被递归清空。
