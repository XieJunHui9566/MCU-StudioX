# 主题、背景与可读性

## 设置入口
使用“视图 → 外观与背景…”或 `Ctrl+Alt+S`。按设置页提供的项目调整主题、背景图、透明度和相关显示效果。用户外观设置与工程文件分开保存，修改主题不需要重建固件。

## 提高文字可读性
1. 先选择适合当前环境的深色或浅色主题。
2. 背景内容较复杂时，提高面板遮挡或降低背景干扰，确认正文、菜单和诊断能清楚阅读。
3. 在编辑区用 `Ctrl+滚轮` 调整字号，或使用“视图 → 编辑器字号”的放大、缩小与恢复默认。
4. 构建与设备日志也可按其支持的缩放操作调整显示；不要只放大整个背景而使工具按钮难以使用。

## 小窗口与滚动
窗口较窄时部分工具栏换行，页面内容可滚动。普通滚轮用于滚动鼠标下方的区域；Ctrl 配合滚轮用于对应区域的缩放。帮助中心可通过顶部“目录”按钮隐藏侧栏，把空间留给正文。

## 背景或主题显示异常
检查原文件是否移动或删除，再到设置重新选择。自定义主题需要符合受支持的数据格式，不能通过任意 XAML 执行代码。若看不清文字，先恢复内置主题和默认字号，再逐项开启效果，便于找到具体原因。
