# 快速开始：完成第一个工程

欢迎页点击“第一个工程引导”，或选择 **帮助 → 第一个工程完整引导**，可以使用交互式七步教程。每一步提供实际操作入口、预期结果、当前工程状态和详细排错帮助。结束后仍可随时重新打开；自由切换步骤不会标记为已编译成功。

## 第一步：确认要创建什么工程
准备芯片的完整料号或 ESP 的 SDK target，再确认打算使用的框架。STM32 等工程可按包提供的模板选择 HAL、SPL 或 FreeRTOS；ESP32 使用 ESP-IDF；MicroPython 是独立工程类型。模板列表中的可用项以已安装器件包为准。

## 第二步：创建并核对工程
1. 打开“文件 → 新建工程…”或按 `Ctrl+N`。
2. 选择厂家、器件包、准确器件和模板。不要只凭“F4”“S3”等简称选型号。
3. 填写工程名称与存放目录，确认摘要中的器件、模板、工具集及版本后创建。
4. 查看左侧工程树，打开模板提供的应用入口。入口可能是 `src/main.c`，也可能是 ESP-IDF 的 `main/hello_world_main.c`。

## 第三步：修改、保存和编译
1. 在应用入口修改一条输出或自己的应用逻辑，按 `Ctrl+S` 保存。
2. 按 `F7` 或选择“构建 → 编译工程”。第一次配置和编译通常比后续编译慢。
3. 查看底部构建输出。最终成功结论和退出代码为 0 才表示本次编译成功；若失败，从日志中第一条实际错误开始查。
4. 固件和原始日志在工程 `.build` 目录。常见产物为 ELF、BIN、HEX、MAP；具体由模板和构建系统决定。ESP-IDF 还会生成 bootloader 与分区表。

## 接下来可以做什么
- 不连接硬件也可编辑、编译、管理插件和使用程序员助手。
- 要下载固件，先按实物选择烧录器或 COM 端口，再核对下载设置和产物。
- 要看日志，打开“工具 → 串口终端”；要画数值曲线，打开“工具 → 串口绘图”。
- 要源码调试，先确认当前器件及探针受支持，并使用含调试信息、已下载到板上的对应固件。

## 常见卡点
器件或模板找不到：先查器件包。工具版本缺失：查“工具 → 工具环境管理…”。头文件或链接失败：查编译排错。不要通过改系统 PATH 来替换工程锁定的内置工具。
