# 编辑、保存与多文件工作区

## 编辑和保存
工程树中双击文件打开标签。`Ctrl+S` 保存当前文件，`Ctrl+Shift+S` 保存全部文件；修改标记消失后表示保存完成。关闭标签或退出时遇到未保存提示，可选择保存、放弃或取消。编译前先确认需要参与本次构建的修改已经保存。

## 常用编辑操作
- `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做，每个文件保留自己的撤销记录。
- `Ctrl+/` 切换当前行或所选行的注释，C/C++ 使用双斜线，CMake 使用井号。
- `Ctrl+F` 查找，`Ctrl+H` 替换；批量修改前先审阅命中范围。
- `Ctrl+滚轮` 调整编辑器字号，也可通过“视图 → 编辑器字号”修改。

## 保存常用代码模板
选中可写源码后，从编辑菜单或右键菜单选择“将选区保存为代码模板…”。`Ctrl+Alt+T` 打开模板管理，双击模板插入；也可输入缩写后按 `Ctrl+Space` 调用。模板支持待填写变量、当前选区和光标位置，插入后可一次撤销。详细步骤和变量语法见“保存与调用常用代码模板”。

## 同时看多个文件
保持多个标签打开，使用工程树或 `Ctrl+P` 快速打开文件。`Ctrl+Alt+Right` 将当前文件移到另一编辑分组；通过视图菜单合并。文件内容、光标和撤销属于对应文档，切换标签不会自动丢弃草稿。

大目录在后台读取，折叠后再展开复用已加载内容。外部程序新增或删除文件后，在工程树按 `F5` 刷新。一个快速打开窗口只发现一次文件，后续输入直接筛选；外部文件有变化时关闭窗口后重新打开。快开最多发现 100,000 个目录、100,000 个文件，显示前 300 项匹配；超限会提示，不把部分发现当作完整结果。

## 只读文件和保存冲突
共享 SDK、部分内部生成配置或磁盘只读文件会标记只读。查看它们可以了解接口和启动关系，应用修改应放到用户源码与根构建配置。若外部程序修改了磁盘文件，先复制当前草稿或查看本地历史，再比较两份内容；不要连续点击保存强行覆盖。

## 重启后的恢复
IDE 会按工作区恢复机制保留编辑会话与恢复草稿。重新打开时核对恢复提示和磁盘版本，确认后再保存。恢复草稿和本地历史可以帮助处理意外关闭；重要工程仍应使用 Git 或独立备份。
