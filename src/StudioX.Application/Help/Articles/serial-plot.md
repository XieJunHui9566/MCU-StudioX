# 串口绘图与数据格式

## 固件该输出什么
默认每行是一组采样值，逗号分隔通道。例如两路 ADC 可连续输出：
```text
4095,1024
4090,1030
4080,1042
```
使用英文小数点，可输出负数、小数或科学计数。保持每组通道数量一致，并发送完整组结束符。普通文字日志、ANSI 颜色和 HEX 二进制不应混入数值流。

## 设置与采集
1. 打开“工具 → 串口绘图”，选择 COM 并匹配固件串口参数。
2. 设置通道分隔符和每组结束符。默认逗号与换行；可按设备改为分号、制表符或其它明确分隔文本。
3. 设置采样周期，点击开始采集。连接后格式锁定，停止后再修改。
4. 首个有效完整组决定通道数量，当前支持 1–16 路。从连续串口流连接时，会先同步到组边界。

## 常见分隔设置
| 设备输出 | 通道分隔符 | 每组结束符 |
|---|---|---|
| 逗号分隔并换行 | `,` | `\n` |
| 分号分隔并 CRLF | `;` | `\r\n` |
| 制表符分隔并换行 | `\t` | `\n` |
| 两竖线分隔、以文本结束 | 两个竖线 | `<end>` |

## 时间怎么理解
周期为 0 时使用电脑接收的单调时钟，相对本次采集起点计时。周期大于 0 时按设定周期排列数据，比如设备每 10 ms 发一组就填 10。USB 分包、缓冲或丢失都会影响观测，页面时间不是硬件时间戳。

## 曲线不出现或断开
确认端口没有被终端占用，设备确实输出数值且包含结束符。无效数字、空字段、通道数量变化等会产生可见错误并断开曲线。先在终端核对原始格式，再断开终端并开始绘图；不要把错误数据补成 0。
