# 安装、启用与使用插件

## 安装入口
打开“工具 → 插件管理”，点击“导入 .studioxplugin…”，选择完整插件归档。安装会检查格式、API 版本、路径和文件哈希。先查看插件名称、版本、作者提供的说明以及诊断，再决定是否使用。

管理页支持按名称、插件 ID、说明或中文能力搜索；右侧能力筛选可只显示调试快照、语言补全、设置、面板或 Agent 工具。找不到结果时清空搜索并选择“全部能力”。列表同时显示版本、API、安装来源及原始诊断。

## 启用和打开面板
1. 在管理列表选择插件，审阅它提供的命令、面板及需要的能力。
2. 明确信任后启用。新安装和更新后的用户插件默认禁用，需要确认当前版本。
3. 通过插件命令、活动入口或对应面板使用功能；部分功能需要打开工程。
4. 点击列表里的“插件设置…”或“工具 → 插件与扩展 → 插件设置…”调整声明的设置。入口需要打开工程并且插件运行成功。

## 调试快照扩展
1. 打开工程，启用具有“调试快照”能力的插件；列表会出现“打开调试扩展”。也可从“工具 → 插件与扩展 → 调试快照扩展…”选择视图。
2. 扩展在独立标签页显示。没有调试连接时显示等待提示，打开扩展不会连接设备或下载固件。
3. 使用正常调试流程连接并暂停。暂停、单步、切换调用栈帧后，扩展自动解释 IDE 已读取的寄存器、变量和调用栈；离线示例明确标为模拟。
4. 继续运行、结束调试或切换工程会清除结果，避免把上次暂停的值当作当前数据。重新暂停后自动显示新结果。
5. 解释失败会显示原始诊断；暂停时点击“重新解释快照”可以重试。禁用插件立即撤销当前视图，关闭标签取消解释并释放订阅。

扩展不增加芯片支持或探针驱动。它使用当前调试器已有数据，不能通过面板按钮任意执行目标表达式或写寄存器。

## 信任意味着什么
插件按当前用户权限执行，独立宿主进程提供故障隔离。文件哈希证明内容完整，不证明作者身份。只启用自己了解来源的插件。经 IDE 请求的工程写入、设备操作等仍需按具体操作处理。

## 更新、禁用和卸载
更新后核对新版本说明及能力，重新信任才会运行。禁用会停止相关会话；卸载用户插件移除其安装内容。内置插件可禁用，安装目录中的内置内容不由用户插件卸载入口删除。插件启用状态与工程源码分开存储。

## 面板空白或命令不见了
确认插件已启用、API 与当前 IDE 兼容、工程上下文满足要求。查看管理页“插件日志与诊断”，保留宿主的具体异常。若某个插件失效，先禁用它并重试相关页面，不需要删除全部插件或重装所有开发环境组件。
