# 安装、启用与使用插件

## 安装入口
打开“工具 → 插件与工具集”，点击“导入 .studioxplugin…”，选择完整插件归档。安装会检查格式、API 版本、路径和文件哈希。先查看插件名称、版本、作者提供的说明以及诊断，再决定是否使用。

## 启用和打开面板
1. 在管理列表选择插件，审阅它提供的命令、面板及需要的能力。
2. 明确信任后启用。新安装和更新后的用户插件默认禁用，需要确认当前版本。
3. 通过插件命令、活动入口或对应面板使用功能；部分功能需要打开工程。
4. “工具 → 插件设置…”调整声明的设置，必要时重新打开面板查看效果。

## 信任意味着什么
插件按当前用户权限执行，独立宿主进程提供故障隔离。文件哈希证明内容完整，不证明作者身份。只启用自己了解来源的插件。经 IDE 请求的工程写入、设备操作等仍需按具体操作处理。

## 更新、禁用和卸载
更新后核对新版本说明及能力，重新信任才会运行。禁用会停止相关会话；卸载用户插件移除其安装内容。内置插件可禁用，安装目录中的内置内容不由用户插件卸载入口删除。插件启用状态与工程源码分开存储。

## 面板空白或命令不见了
确认插件已启用、API 与当前 IDE 兼容、工程上下文满足要求。查看管理页“插件日志与诊断”，保留宿主的具体异常。若某个插件失效，先禁用它并重试相关页面，不需要删除全部插件或重装所有工具链。
