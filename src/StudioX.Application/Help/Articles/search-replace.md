# 查找、替换与批量修改

## 当前文件
`Ctrl+F` 打开查找，`Ctrl+H` 打开替换。填写查找词，按需要选择大小写、整词或正则表达式。先看匹配位置，再替换单项或全部。当前文件替换修改编辑缓冲区，确认正确后用 `Ctrl+S` 保存；可用撤销回退。

## 整个工程
1. 按 `Ctrl+Shift+F` 在工程中查找，或按 `Ctrl+Shift+H` 进入工程替换。
2. 填写关键词与文件范围，先查看结果列表，双击命中项核对上下文。
3. 替换时先生成预览，审阅每个文件的前后差异，再选择需要应用的项目。
4. 应用后检查问题列表和源码，保存并重新编译。

## 正则替换示例
例如把 `channel_12` 改成 `adc_12`：查找 `channel_(\d+)`，替换为 `adc_$1`。先在小范围确认匹配，再扩展到全工程。非法正则、超时或超出限制会拒绝修改，不通过分次试错来覆盖不确定的文件。

## 重命名变量和函数
对 C/C++ 符号优先使用 `F2` 或“编辑 → 重命名 C/C++ 符号…”，它基于语义引用并提供修改预览。普通文本替换也会命中注释、字符串和同名但无关的符号，适合明确的文本批量修改。

## 预览失效怎么办
出现 `WORKSPACE_EDIT_STALE` 等提示，说明文件或编辑版本已经变化。先保留当前内容，重新搜索并生成新的预览。不要把旧预览强行应用到新文件；可到“编辑 → 本地历史…”核对修改前的版本。
