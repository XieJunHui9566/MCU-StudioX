# 安装精确版本工具和插件

打开“工具 → 软件与组件分发…”。目录可以是明确的 HTTPS 地址或本地 catalog.json；点击“读取目录”后才读取内容，打开页面不自动联网。

## 选择和预览

按工具集、插件或组件筛选，也可搜索 ID、名称和许可证。选中条目后核对精确版本、来源链接、许可、更新说明、插件 API、归档 SHA-256，以及下载和展开大小。磁盘预估包含缓存和安装暂存；空间不足时不能开始安装。

“工程所需工具”定位当前工程锁定的 ID/版本。目录缺少该版本时，换用正确目录或到“工具占用与升级管理”导入 .studioxtools。不能用“最新版本”替代缺失的工程锁定版本。

“下载并预览安装”先检查归档长度和 SHA-256，再展示实际安装信息。工具完整清单由安装服务校验。工具版本可以并存，安装新版本不改已有工程锁定；切换版本通过工程现有工具配置明确执行。原版本保留时可以切回，也可从工具管理恢复已归档版本。

## 来源与信任

没有公钥时“发布者”只是目录自述，哈希验证内容完整性。“选择发布者公钥”从可信途径取得 PEM 公钥后，验证目录旁的 catalog.json.sig；签名匹配所选密钥并显示密钥指纹。不要仅因为公钥和目录来自同一地址就认定发布者可信。取消公钥验证恢复未验证标记。

## 插件更新与回退

插件安装后默认停用，更新和回退都会撤销旧信任。到插件管理页审阅能力后重新启用。“回退插件”使用更新前保存并校验的归档；普通安装仍拒绝降级。插件运行在独立进程，仍拥有当前用户权限。

## 基础版与完整版

默认完整版随带准备好的工具链及器件包，适合开箱使用。基础版保留自包含 IDE、语言服务、Git 和插件宿主，工程工具集另行选择安装。两种发行共用产品身份和版本规则；基础版不是在线自动更新服务，IDE 本身仍由安装包更新且拒绝降级。

当前目录基础设施和本地示例已提供，公共目录、发布者密钥和产品代码签名仍需正式配置，页面不会冒充已存在的官方市场。
