# 快捷键速查

## 工程与窗口
| 操作 | 快捷键 | 说明 |
|---|---|---|
| 打开帮助中心 | `F1` | 不需要打开工程 |
| 新建工程 | `Ctrl+N` | 选择器件和模板 |
| 打开工程 | `Ctrl+O` | 选择工程根目录 |
| 保存当前文件 | `Ctrl+S` | 写入当前文档 |
| 保存全部 | `Ctrl+Shift+S` | 检查每个保存结果 |
| 关闭当前标签 | `Ctrl+W` | 未保存时处理提示 |
| 关闭工程 | `Ctrl+Shift+W` | 先结束相关操作 |
| 编译工程 | `F7` | 查看完整构建输出 |
| 工程窗口 | `Alt+1` | 显示或隐藏 |
| 底部工具窗口 | `Alt+4` | 显示或隐藏 |
| 外观设置 | `Ctrl+Alt+S` | 主题和背景 |
| 工程终端 | Ctrl+反引号 | 工程上下文的终端 |

## 编辑与搜索
| 操作 | 快捷键 | 说明 |
|---|---|---|
| 撤销 | `Ctrl+Z` | 当前文件独立记录 |
| 重做 | `Ctrl+Y` / `Ctrl+Shift+Z` | 恢复撤销的编辑 |
| 切换行注释 | `Ctrl+/` | 支持的可写源码 |
| 当前文件查找 | `Ctrl+F` | 可用大小写、整词、正则 |
| 当前文件替换 | `Ctrl+H` | 先核对匹配范围 |
| 工程查找 | `Ctrl+Shift+F` | 跨文件定位 |
| 工程替换 | `Ctrl+Shift+H` | 审阅修改预览 |
| 快速打开文件 | `Ctrl+P` | 当前工程文件 |
| 搜索符号 | `Ctrl+T` | 需相应分析服务 |
| 命令面板 | `Ctrl+Shift+P` | 按功能名查命令 |
| 代码模板 | `Ctrl+Alt+T` | 保存、管理和插入常用代码 |
| 移到另一编辑分组 | `Ctrl+Alt+Right` | 当前编辑标签 |
| 调整字号 | `Ctrl+滚轮` | 在对应文字区域操作 |

## 代码分析
| 操作 | 快捷键 | 说明 |
|---|---|---|
| 代码提示与模板缩写 | `Ctrl+Space` | 模板不依赖语言服务器 |
| 参数提示 | `Ctrl+Shift+Space` | 函数调用上下文 |
| 跳到定义 | `F12` | C/C++ 或 Python 静态导航 |
| 跳到声明 | `Ctrl+F12` | 按语言支持情况 |
| 查找引用 | `Shift+F12` | 查看并定位结果 |
| 导航后退 | `Alt+Left` | 回到上一个位置 |
| 重命名 C/C++ 符号 | `F2` | 先审阅修改预览 |
| 格式化文件 | `Ctrl+Alt+F` | 可用时生成预览 |
| 快捷修复 | `Alt+Enter` / `Ctrl+.` | 查看当前可用修复 |

## 调试
| 操作 | 快捷键 | 说明 |
|---|---|---|
| 启动或结束 | `Ctrl+F5` | 支持目标的调试会话 |
| 运行 | `F5` | 当前活动会话 |
| 设置或删除断点 | `F9` | 当前源码位置 |
| 启用或禁用断点 | `Ctrl+F9` | 保留断点设置 |
| 条件或日志断点 | `Shift+F9` | 查看断点设置 |
| 逐过程 | `F10` | 通常越过函数调用 |
| 单步进入 | `F11` | 进入函数 |
| 跳出函数 | `Ctrl+F11` | 返回调用方 |
| 运行到光标 | `Ctrl+F10` | 核对可执行位置 |

## 快捷键没反应
先看当前焦点是否在终端、串口发送框或其它输入控件，再看工程、语言服务和调试状态是否满足条件。对应菜单项灰色时，快捷键通常也不可用。串口发送框中的 `Ctrl+Enter` 用于发送，需要先连接并核对内容。
