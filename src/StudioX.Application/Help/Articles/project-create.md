# 新建工程与选择模板

## 从哪里开始
打开“文件 → 新建工程…”或按 `Ctrl+N`。先保存当前修改，再填写新工程位置。新目录用于存放源码、工程元数据和后续构建产物；安装目录不是工程存放目录。

## 选择顺序
1. 选厂家，缩小器件包范围；也可以输入完整料号搜索。
2. 选器件包和具体器件，核对 Flash、RAM、封装以及包说明。
3. 选模板。裸机、HAL、SPL、HAL+RTOS 和 SPL+RTOS 等仅在对应包确实提供时出现。
4. ESP 工程按实际 target 选择，如 `esp32s3`；Flash 和 PSRAM 还需按模组参数配置。
5. 审阅工程名称、目录和开发环境组件版本，然后创建。

## 创建后的检查
打开应用入口和根 `CMakeLists.txt`，确认模板内容与需求一致。在“工具 → 器件与模板”核对工程信息。工程锁定创建时选择的器件包、模板和开发环境组件，不会因为电脑另装了新版 GCC 自动切换。

## 模板怎么选
初次验证可选最小示例或 hello-world，先确认构建环境。需要外设库时选择相应 HAL/SPL 模板；需要任务调度时选择包明确提供的 FreeRTOS 模板。MicroPython 工程与 C/C++ 固件工程分开创建，不把 Python 脚本当作 C 源文件编译。

## 创建失败时
查看原始错误是目录已存在、不可写、器件包缺失还是开发环境组件版本缺失。保留目录中的已有文件，不通过覆盖旧工程来处理错误。若料号未被收录，先补充对应新格式器件包，而不是选择相近型号后手工猜内存布局。
