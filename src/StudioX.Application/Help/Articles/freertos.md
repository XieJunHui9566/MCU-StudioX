# FreeRTOS 状态与变量绘图

## 使用前提
先创建对应器件包提供的 FreeRTOS 模板，成功编译并下载含调试信息的固件。启动支持的实机调试后，打开“调试 → FreeRTOS 状态”。任务、堆和同步对象信息取决于固件配置与可读的内核符号。

## 看懂状态
- 任务名称与状态：结合任务调度和阻塞原因检查，暂停时看到的只是当前快照。
- 堆：观察剩余空间和分配失败，任务栈与内核对象都可能消耗堆。
- 栈水位：关注页面标出的单位和最小剩余量，不能把词数直接当字节数。
- 同步对象：注册过的队列、信号量或互斥对象可按实际支持范围查看；未注册不等于对象不存在。

## 排查任务问题
1. 暂停目标并刷新数据，确认采集来源与状态。
2. 查看任务是否阻塞、优先级是否合适，以及栈水位是否接近耗尽。
3. 结合调用栈、局部变量和应用日志判断等待对象与超时。
4. 调整代码后重新编译、下载，再重复观察。单次快照不能证明任务长期稳定。

## OpenOCD 变量绘图
“调试 → OpenOCD 变量绘图”复用当前调试会话读取支持的 SRAM 全局变量，适合观察少量数值变化。选择真实符号并设置采集参数。采样会占用调试通信，时间来源和采样方式以页面说明为准。

## 选择串口还是调试绘图
串口绘图由固件主动输出数值文本，便于连续记录；调试绘图适合已有全局变量，受调试读取与采样能力限制。两种方式的时间戳都需要按各自来源理解，不能把电脑接收时间当作 MCU 的精确硬件采样时刻。
