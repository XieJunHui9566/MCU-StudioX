# AI 接口与工程助手

## 配置接口
打开“工具 → AI 接口设置…”，填写兼容服务的 API 地址、模型标识和 API Key，保存后打开窗口右上角 AI 聊天栏。服务地址和模型名称需使用服务商提供的实际值；未配置当前接口时可以查看已有历史，但无法正常发起新的模型请求。

## 提问时提供什么
给出目标功能、当前工程、完整报错和期望结果。例如：“这个 ESP32-S3 工程在配置阶段失败，日志中出现 XTENSA_GNU_CONFIG，请定位第一个错误并说明涉及文件。”比只写“编译不了”更容易得到可核对的建议。

## 工程工具与修改
助手可通过当前提供的工程工具读取信息、搜索源码和查看诊断。执行修改前审阅涉及文件、修改预览和具体操作；涉及保存、构建或设备操作时，按界面中的实际请求处理。保留原始诊断，确认修改后重新验证结果。

## 网络与凭据
API 请求会把所提供的对话和上下文发送给选择的服务。密钥放在接口设置中，不写进源码或聊天里的公开示例。联网检索配置与模型接口配置各自核对；模型能回答问题并不表示检索服务已经可用。

## 请求失败
看具体 HTTP 或服务错误，分别检查 API 地址、模型名称、密钥、配额、代理及网络。保留错误码和不含密钥的诊断。若建议涉及芯片规格或未经运行的代码，需要对照器件资料、实际编译和设备结果确认。
