# 串口终端：接收、发送与 HEX

## 连接步骤
1. 打开“工具 → 串口终端”，刷新端口并选择实际 COM。
2. 按固件参数设置波特率、数据位、校验位、停止位和流控。常见配置为 115200、8 数据位、无校验、1 停止位，实际以固件为准。
3. 选择接收编码，点击连接；观察状态与接收计数。
4. 连接后基础参数锁定，需断开后修改。结束后断开或关闭标签释放端口。

## 文本与原始字节
UTF-8 用于相应编码的文字日志，GB2312/GBK 用于匹配的中文输出，HEX 直接查看字节。乱码先检查波特率，再检查字符编码。显示为 HEX 时，ASCII 字母 A 对应字节 `41`，字符“1”对应 `31`。

## 发送示例
文本命令可填写 `help`，按设备要求选择无结束符、CRLF、LF 或 CR，再发送。`Ctrl+Enter` 发送当前内容。
HEX 可填写 `01 A5 00 FF` 或连续十六进制。开启字符转义后，可使用 `\r`、`\n`、`\t` 和 `\xHH` 等；转义后的字符仍按所选发送编码处理。需要任意原始字节时选择 HEX。非法字节或不完整半字节会拒绝发送。

## ANSI 与定时发送
ANSI 显示可呈现设备日志颜色和部分控制序列。排查原始协议时使用 HEX，或关闭 ANSI 查看可见转义。定时发送前先用单次发送确认命令和结束符；掉线会停止定时发送，发送超时可能已经发出部分内容，需检查设备响应再决定重试。

## 端口所有权
同一端口不能同时被串口终端、绘图、MicroPython 或下载工具占用。DTR/RTS 可能影响某些板的复位和启动模式，按设备接线需求设置。无数据、占用或乱码时继续阅读串口故障主题。
