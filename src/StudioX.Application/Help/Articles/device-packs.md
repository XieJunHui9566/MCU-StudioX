# 器件包与模板管理

## 包里包含什么
器件包声明可用器件、内存布局、模板、启动及链接支持、下载和调试能力。文件扩展名为 `.mcupack`，但只有 StudioX Pack 格式 1 可导入；扩展名相同的旧格式不代表兼容。

## 导入与查找
1. “文件 → 导入器件包…”选择包文件，查看校验结果。
2. “工具 → 器件与模板”查看已安装包，按厂家或完整料号搜索。
3. 新建工程时选择确切器件和模板，核对包版本及摘要。
4. 若通过 GitHub 获取包，使用菜单中的检查更新或同步入口，下载完成后再次核对所需型号是否确实收录。

## 更新与已有工程
安装新包并不自动改写已有工程的源码、SDK 和工具锁。新的工程使用所选版本；旧工程仍应按自己的锁定信息检查。不要在旧工程中直接替换链接脚本或启动文件来假装升级了器件支持。

## 型号或模板缺失
先检查是否选错厂家、子系列、容量或包版本。某系列可编译不代表所有容量、封装和探针都已经支持。界面未提供下载或调试时，以包和目标支持说明为准；编译通过也不代表实板已经验收。

## 导入失败
格式版本、完整哈希、文件路径和包清单错误会保留原始诊断。请保留失败包和具体错误；重新获取匹配格式的完整归档。不要解压后随意改清单或删除校验字段来绕过检查。
