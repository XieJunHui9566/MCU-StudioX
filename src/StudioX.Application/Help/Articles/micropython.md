# MicroPython 工程与设备会话

## 选择工程类型
MicroPython 工程提供 Python 脚本编辑和设备操作。RP 系列等同一板型也可能有独立 C/C++ 固件模板，创建时应明确选择自己要用的类型。普通 Python 静态编辑也不等于已经连接并运行了设备。

## 使用设备会话
1. 确认板上已有兼容的 MicroPython 固件，并检查电脑识别到的 COM 端口。
2. 打开对应工程和 MicroPython 页面，明确选择端口后连接。
3. 查看 REPL/设备反馈，确认设备可响应，再执行页面提供的脚本和文件操作。
4. 运行前保存并核对当前脚本。设备文件操作与电脑源码操作需分别检查目标路径和结果。

## 编辑与排错
Python 有语法配色和静态导航，工程内定义及显式导入可定位；MicroPython 的固定 API 声明可只读查看。设备抛出的异常以实际回溯为准，先看报错行、导入模块和板上的固件功能是否匹配。

## 端口占用与脚本运行
同一 COM 端口只允许一个拥有者。串口终端、串口绘图、MicroPython REPL 和下载工具若要使用同一端口，需要先结束已有会话。掉线后先核对设备状态，再手动重连；不要自动重复可能已执行过的写入或脚本。

## 会话结束
停止当前脚本后按页面操作断开连接，再启动其它串口工具。关闭页面或工程时注意未保存源码与设备会话状态。连接失败不能通过重复按编译键修复，优先查看端口和设备固件是否正确。
