# 下载固件与选择烧录器

## 下载前核对
确认当前工程器件与板上完整料号一致，电源、地线和下载连线正确。选择器件包和应用已支持的烧录器；STM32、CH32、AG32、RP 和 ESP 的下载通路由具体目标决定，不通用套用某个探针配置。

## 普通探针下载
1. 在“构建 → 下载设置…”选择实际烧录器、接口、速度及需要时的序列号。
2. 保存工程设置；更换烧录器后重新检查速度与序列号。
3. 先编译工程，查看本次成功结果和产物。
4. 点击“构建 → 下载固件”，审阅目标和下载内容，再执行。
5. 查看写入、校验及最终结果。出现中途失败时保留原始设备日志，先检查当前板上状态。

## ESP 串口下载
ESP 工程使用专用下载页面，明确选择实际 COM 端口，核对 Flash 参数和多映像布局。应用、bootloader、分区表及其它声明映像按本次原生配置共同写入。操作前断开占用该端口的串口工具。

## PICkit3 普通下载
PIC16F877A 工程点击下载后保存并编译，直接写入当前固件并完成一次校验，不回读或备份板上原程序。仅连接一个 PICkit3 时自动选择，多个时选择本次使用的序列号，不另弹下载确认框。目标板使用独立电源。

下载前只读取器件身份与配置，核对目标和保护状态；保留 EEPROM 与用户 ID。固件、源码或设置发生变化时须重新构建和预检。输出保留阶段耗时与原始工具诊断，工具失败、取消或未完成校验均不能显示成功。

普通下载与源码调试是独立流程，调试仍按其会话恢复规则退出。

## 下载按钮灰色
检查工程是否打开、目标是否提供下载能力、工具是否完整、是否存在构建或调试会话。当前目标未开放能力时应先查看支持范围，不通过手工改清单放行未知器件。

## 下载后与源码调试
调试使用包含符号的 ELF 和对应板上程序。源码、配置或工具变化后重新编译，并按需要下载新固件。解锁、选项字节、OTP 和整片擦除会改变额外设备状态，只在自己明确需要且了解后果时使用相应独立流程；日常连接排错先处理探针和连线。
