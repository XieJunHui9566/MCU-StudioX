# LVGL PC 预览

## 什么时候使用
在电脑上预览已有 LVGL UI，可减少为每次界面调整重新下载板卡的次数。PC 预览需要明确的 LVGL 库、UI 源码、配置头、入口和资源；当前向导支持的版本范围以页面检测结果为准，现有实现针对 LVGL 8.3.x。

## 配置步骤
1. 打开工程，进入“工具 → LVGL PC 预览”。
2. 选择 LVGL 根目录并检查库和版本，发现多份库时明确选择一份。
3. 选择工程内 UI 目录，分析页面、字体、图片、头文件、配置与入口。
4. 审阅 PC 入口、源码、包含目录和需要复制的运行资源，检查依赖。
5. 保存配置，再选择启动预览；查看电脑端编译和窗口结果。

## 哪些文件需要适配
MCU 的 GPIO、HAL、启动、中断和 RTOS 依赖通常需要从 PC 入口分离，或者提供明确的电脑端实现。C 数组形式的图片、字体作为源码加入；运行时从文件加载的资源目录加入资源映射，并按工程相对路径访问。

## 预览失败
按完整 C/C++ 编译及链接诊断检查，不通过生成一个空白页面来替代缺失 UI。核对 LVGL 版本、配置头、入口函数、资源路径和解码器。重建失败时页面可能保留上一次成功窗口，需看旧版本提示，不能据此认定最新代码已生效。

## 配置保存
工程 `.studiox/lvgl-preview.json` 保存 PC 预览配置，与 MCU 固件构建分开。电脑预览验证 UI 和 PC 适配逻辑，实际显示屏、触摸、内存与设备外设行为仍需在目标上检查。
