# 保存与调用常用代码模板

## 将常用代码保存起来
1. 在可写的源码文件中选中需要复用的代码。
2. 右键选择“将选区保存为代码模板…”，或在编辑菜单中选择该命令。
3. 填写名称、适用语言和说明。设置一个容易记住的缩写，例如 `mylog`。
4. 选择“个人”或“工程”，检查正文后点击“保存模板”。保存模板不会保存或修改当前源码。

选区的基础缩进会被去掉，以便在其他位置插入时使用当地缩进。代码中的美元符号会自动写成 `$$`，调用时恢复成普通 `$`。例如 CMake 中的 `${PROJECT_SOURCE_DIR}` 保存后显示为 `$${PROJECT_SOURCE_DIR}`，插入时仍是原来的代码。

## 调用模板
- 按 `Ctrl+Alt+T`，或选择“编辑 → 代码模板…”。搜索名称、缩写或说明，查看右侧正文，然后双击模板或点击“插入选中模板”。
- 在编辑器输入缩写后按 `Ctrl+Space`，选择带“模板”标识的条目，再按 Enter 或 Tab。模板可以在语言分析服务尚未启动时使用。
- 若模板包含待填写变量，会先显示变量与插入预览。填写后点击“插入”；同名变量只填写一次。

从模板管理窗口插入时，模板替换当前选区；没有选区则插入到光标处。缩写调用替换光标处的缩写。每次插入可用一次 `Ctrl+Z` 撤销，用重做恢复。源码仍为未保存状态，检查后使用 `Ctrl+S` 保存。

内置的 C/C++ 模板有 `sxif`、`sxfor`、`sxfunc`、`sxguard`；Python 有 `sxdef`；CMake 有 `sxsources`。这些模板不依赖芯片型号。内置模板可复制为个人或工程模板后修改。

## 变量写法
| 写法 | 作用 |
|---|---|
| `${name:默认值}` | 定义一个待填写的单行变量 |
| `${name}` | 引用同名变量；未设置默认值时从空文本开始 |
| `${cursor}` | 插入完成后的光标位置，最多一个；未指定则在末尾 |
| `${selection}` | 模板管理窗口打开前的选区，可用于包裹已有代码 |
| `${fileName}` | 当前文件名，包含扩展名 |
| `${fileStem}` | 当前文件名，不含扩展名 |
| `$$` | 普通美元符号，不参与变量替换 |

例如将下面的正文保存为 C/C++ 模板，填写 `condition` 后即可包裹选区：

```c
if (${condition:ready != 0})
{
    ${selection}${cursor}
}
```

变量名使用字母或下划线开头的标识符。重复变量的默认值必须一致，默认值不能换行或包含 `{`。填写值按普通文本插入，不再次展开其中的 `${...}`。这是文本模板，不能执行脚本或读取环境变量。

## 个人和工程模板
- 个人模板保存在 IDE 用户数据目录的 `code-templates/templates.json`，供所有工程使用。
- 工程模板保存在当前工程的 `.studiox/code-templates.json`，可以提交到工程仓库，与同事共享。未打开工程时只能创建个人模板。
- 不同位置的同名缩写会分别显示“个人”“工程”标签，由你选择；同一个库、同一种语言不能重复使用缩写。

模板管理支持新建、编辑、复制、删除和语言筛选。没有可写文件时可以管理模板，插入按钮会停用。

## 插入或保存失败
若弹窗期间文件、选区或只读状态变化，IDE 会拒绝插入，请关闭后重新选择位置。模板文件被另一个 IDE 或外部程序修改时，保存会提示冲突，请重新打开模板管理并核对新内容。

每个模板库最多 500 个模板，正文最多 65,536 字符，待填写变量最多 32 个，展开结果最多 262,144 字符，JSON 文件最多 4 MiB。格式版本仅支持 1。JSON 或变量语法错误会显示原始诊断并保留原文件，修正前不会静默覆盖模板库。
