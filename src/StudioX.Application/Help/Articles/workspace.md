# 认识工作台与工具窗口

## 窗口各部分做什么
- 左侧工程树：查看当前工程文件，双击打开源码、头文件或配置文件。工程信息页可核对器件、模板及编译参数。
- 中间标签区：同时打开多个文件或工具页。标签中的修改标记表示内容尚未保存。
- 底部工具区：查看构建输出、设备输出、问题列表和调试数据。源文件诊断通常可双击跳到位置。
- 工具菜单：串口终端、串口绘图、器件与模板、插件、开发环境组件、工程终端等入口。

## 如何快速找回窗口
1. “视图 → 欢迎页”回到欢迎入口，不关闭当前工程。
2. `Alt+1` 显示或隐藏工程窗口，`Alt+4` 显示或隐藏底部工具窗口。
3. “视图 → 问题列表”集中查看错误和警告，构建输出保留完整上下文。
4. `Ctrl+Shift+P` 打开命令面板，输入功能名来找命令。

## 标签与编辑分组
`Ctrl+W` 关闭当前标签；关闭未保存文件时按提示保存、放弃或取消。`Ctrl+Alt+Right` 将当前编辑文件移到另一分组；“视图 → 合并编辑分组”恢复单组布局。分组改变不会把未保存的内容自动写入磁盘。

## 页面没有内容或按钮灰色
先确认是否已经打开工程，以及当前文件和器件是否支持该功能。源码调试窗口需要活动调试会话；某些插件面板需要先启用插件或打开工程。帮助中心、串口工具等可独立使用。若底部输出不见了，可先按 `Alt+4`，无需重装软件。
