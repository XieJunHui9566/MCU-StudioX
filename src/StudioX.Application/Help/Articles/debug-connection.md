# 调试连接向导与退出恢复

## 开始连接

先保存源码并成功编译，核对工程器件和烧录器。按 Ctrl+F5 或“调试 → 启动 / 结束调试”，完成构建后出现连接窗口，点击“开始连接”。普通附加会暂停已运行程序；连接向导不下载固件。

STM32 + ST-Link 可明确选择“复位连接”。只有需要在复位状态下连接、并已连接 NRST 时才使用；此选项会复位并暂停目标。其它组合由配置校验拒绝，不猜测模式。

## 读懂阶段

- 本地准备：源码、构建回执、ELF 和锁定工具必须一致。
- 探针连接：取得独占租约并启动工具；检查 USB、探针驱动和占用。
- 目标识别：核对器件身份、容量及目标访问；检查供电、共地、SWDIO/SWCLK 和复位。
- 调试器启动：载入当前 ELF，不使用来历不明的调试符号。
- 固件校验：只读比较当前固件与板上内容，校验完成前不显示源码快照。
- 暂停快照：读取源码位置、寄存器和断点。
- 退出恢复：结束会话时核对目标是否恢复运行。

阶段来自实际工具与检查结果。等待秒数采用宿主时间，不表示完成百分比；大固件校验可能较慢。

## 核对固件与符号

只读校验需要当前成功编译产物与板上程序一致。若校验失败，先查看原始工具输出，再确认板上固件的来源、目标器件和当前 ELF；不要反复更换符号文件来绕过检查。需要下载时，应结束调试会话，明确选择要下载的固件并按下载流程操作，然后重新连接。

## 取消、结束与失败

“取消连接”会请求取消并等待清理，窗口不会提前丢弃恢复结果。连接成功后关闭窗口只关闭记录页，调试会话继续存在。通过调试结束按钮退出后，再打开“调试 → 调试连接记录…”查看退出恢复。

“已确认运行”需要工具给出恢复证据；“未确认”保留错误和原始日志路径，需要检查设备。失败阶段及异常完整保留。重新插拔探针前先结束会话；不因连接失败自动擦除、解除读保护或烧录。
