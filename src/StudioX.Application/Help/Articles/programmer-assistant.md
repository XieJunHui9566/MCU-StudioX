# 程序员助手：位运算与进制转换

## 从哪里打开
打开工程，在“工具 → 插件管理”确认“程序员助手”已安装并启用，再点击左侧图标或“打开程序员助手”。它会打开独立计算器窗口，重复打开会回到同一窗口。关闭窗口保留本次会话输入；停用插件或关闭工程会结束窗口。原插件名为“位运算实验室”，插件身份保持连续。新版界面需要支持独立窗口和程序员计算器的 IDE 构建。

## 先选位宽和数值解释
通过 BYTE/WORD/DWORD/QWORD 选择 8、16、32 或 64 位，再选择有符号或无符号解释。固定宽度结果按所选位宽截取：8 位时 `0xFF + 1` 得到 `0x00`。主动缩窄位宽会保留低位，直接输入超出位宽的数仍会报错。同一位模式 `0xFF` 在 8 位无符号下是 255，在有符号下是 -1；改变解释不会改变这些位。

## 进制转换
用键盘或计算器按键输入整数或表达式，输入后自动更新结果及 HEX、DEC、OCT、BIN 四种读数，保留输入和光标；移位与循环移位键每次立即执行一位，无需等号。Esc、CE 或清空立即归零，= / Enter 保留为显式提交。点击进制行切换输入进制，已有数值会保持。A–F 仅在 HEX 模式可按；显式 `0x`、`0d`、`0o`、`0b` 前缀可混合使用。检查位宽后再复制结果，避免把 8 位结果误用到 32 位寄存器掩码。

## 位运算示例
| 运算 | 输入示例 | 结果 |
|---|---|---|
| AND 位与 | `0xF0 & 0x0F` | `0x00` |
| OR 位或 | `0xF0 OR 0x0F` | `0xFF` |
| XOR 异或 | `0xAA XOR 0xFF` | `0x55` |
| NOT 取反，8 位 | 对 `0x0F` 取反 | `0xF0` |
| 左移，8 位 | `1 << 3` | `8` |
页面还提供 NAND、NOR、左右移位和循环移位。右移时确认逻辑右移还是算术右移；高位如何填充会影响负数的解释。

## 表达式与位域
用表达式区输入整数运算，必要时加括号明确先后顺序。右侧逐位视图支持点击翻转某一位，显示完整 8–64 位。切到位域工具后，以最低位为 0，填写起始位和长度，可提取、置位、清零、翻转或替换一段位。例如从 `0x12345678` 的第 8 位取 8 位，结果为 `0x56`。同时显示低地址到高地址的小端/大端字节，可复制 C 定宽常量和包含位域掩码的代码。窄窗口中 MCU 工具位于键盘下方，可滚动访问。

## 使用结果时
输入非法数字、除数为零或位域越界时先修正提示，不沿用上一次结果。该工具计算数值和位模式，寄存器读写仍由你的代码或相应调试功能完成。
