# 优化等级与调试信息

## 设置入口
打开工程后进入“工具 → 器件与模板”，找到“编译参数”卡片。选择优化等级与调试信息，然后点击“保存参数”。恢复“工程默认”也要保存，下一次构建才会使用新设置。

## 怎么选择优化
| 选项 | 适合场景 | 使用时注意 |
|---|---|---|
| 工程默认 | 保留原模板或原生 SDK 行为 | 沿用工程实际配置 |
| `-O0` | 调查源码执行顺序 | 体积与速度可能变差 |
| `-Og` | 常规源码调试 | 通常比高优化更容易观察变量 |
| `-O1` / `-O2` / `-O3` | 逐步考虑速度优化 | 变量可能被消除，单步可能跳行 |
| `-Os` | 优先减小体积 | 仍需测试速度和实时性 |

## 调试信息
源码调试可使用 `-Og` 与 `-g3`。`-g2` 提供标准调试信息；`-g3` 还包含宏信息；`-g0` 不生成调试信息。选择 `-g0` 后需恢复信息并重新编译、下载，才能期望源码断点与变量观察正常工作。

## 设置保存在哪里
编译设置保存在工程 `.studiox/build.json`，与用户主题、器件包和工具本体分开。构建、下载或调试期间修改入口会受状态限制。保存新参数会使旧的构建凭据失效，下次编译会按新环境配置缓存。

## 参数不生效
检查本次构建输出和真实编译命令，而不是只看下拉框。如果自定义构建规则不支持参数注入，保留诊断，选择工程默认并维护工程自己的 CMake。优化设置不会修正错误的中断声明、时钟参数或链接脚本。
