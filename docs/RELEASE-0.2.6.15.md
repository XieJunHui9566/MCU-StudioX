# MCU StudioX 0.2.6.15

Windows x64 发行：轻量安装器、完整安装器及同一提交的源码。Linux 暂不支持。

## 新建工程与工具

- Arduino 纳入通用起始模板：ATmega328P（Uno/Nano）、ESP32-WROOM-32、C3、C5、C6、S3。选择准确芯片后再选 Arduino 或原生模板，保留 ESP-IDF 工作流。
- Arduino CLI 1.5.1、AVR 核心 1.8.8、ESP32 核心 3.3.8，按工程锁定版本；真实编译证据与实板上传验收分开。
- 新增 122 个经典 PIC16 型号和七个器件包。容量来自官方 PIC16Fxxx DFP 1.9.176 的精确型号数据，区分 12/14 位指令字及分银行 RAM。支持新建、C 编辑、寄存器补全、独立 XC8 4.00 编译和 HEX/ELF 生成。
- PIC 编译无需完整 MPLAB IDE。XC8 为专有工具，公开安装器不重新分发；请从官方取得并接受许可，再用安装目录的 `准备PIC工具.ps1` 准备本机组件。PICkit/IPECMD 烧录、PIC 源码调试、PIC18/24/dsPIC 尚未接入。

## 安装和器件包

轻量版包含 IDE、Git、语言服务、插件宿主和器件包，保留本机已有开发组件。完整版另外附带可公开分发的既有开发环境及 Arduino AVR/ESP32 组件；完整安装器的 `.exe` 和全部同名 `-*.bin` 必须放在同一目录，运行 `.exe`。

覆盖安装保留工程、锁定工具、用户主题、字体柔光、动态壁纸和有效插件状态。导入新版器件包后，只有同 ID、工具身份相同且完整覆盖旧器件/模板的版本才会自动清理；已建工程使用自己的器件副本，不随仓库清理升级。工具组件不纳入器件包清理。

独立交付 Arduino AVR 包、支持 Arduino 的 ESP32 子系列包及七个 PIC 包；完整器件目录另附 ZIP 和 SHA-256。相同 ID 的可替代旧包附件在新版上传核验后清理，不删除其他器件包或旧 IDE 发行历史。

## IDE 本体源码改动

本版本涉及本体改动：Packages 增加 PIC12/14 元数据与严格型号目录；Engine 增加 PIC 工程、XC8 构建及 HEX 凭据，并接入 Arduino 构建与组件锁；Application 增加健康检查、PIC 语言分析与 Arduino 模板服务；Desktop 调整通用模板、编译结果及未实现硬件入口的显示。现有插件契约没有完整构建后端扩展点，因此这部分由核心服务实现。外观工作室继续作为独立插件交付。

软件验收包括 PIC 全型号真实编译、边界与语言服务检查、Arduino 模板与编译检查、维护回归、真实 WPF、安装升级及用户数据保留。具体通过结果以 Release 的验证记录和摘要为准；本次没有硬件烧录或调试验收。安装器未配置代码签名。
