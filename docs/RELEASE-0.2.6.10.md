# MCU StudioX 0.2.6.10

本次提供 Windows x64 完整版和轻量版，仍为开发预览版。产品、安装器、程序集和 Windows 文件版本均为 `0.2.6.10`。

## 选择安装包

| 安装包 | 内容 | 首次工程 |
| --- | --- | --- |
| `MCU-StudioX-0.2.6.10-win-x64-Setup.exe` | IDE、70 个器件包、Git、clangd、插件宿主与原有开发环境组件 | 预装版本对应的工程可直接使用 |
| `MCU-StudioX-0.2.6.10-win-x64-Light-Setup.exe` | 相同 IDE、器件包、Git、clangd 和插件能力，不含开发环境组件 | 按工程需求从 GitHub 获取或手动导入组件 |

两种版本共用安装位置和用户数据。可覆盖升级旧版，也可在同一目录互换；已有组件按 ID/版本整个目录保留，不混合覆盖。安装前关闭 IDE，安装器不强制结束进程。不修改系统 PATH、用户工程或组件锁，也不安装 USB 驱动。

## 开发环境组件

- 工具菜单按用途分组，统一称呼为“开发环境组件”；管理页使用与工作台一致的主题和透明背景。
- GitHub 获取与手动 `.mcutoolchain` 导入两种模式共用校验与安装服务。新归档使用 7z，读取兼容已有 ZIP 格式。
- 公开目录强制验证内置公钥签名，下载核对大小和 SHA-256；只在用户主动获取时联网。
- 支持并存版本、完整校验、禁用/启用、移入可恢复区、恢复、永久删除和调试环境检查；依赖与占用会阻止不安全的删除。
- 打开 IDE 不全量校验所有组件，工程使用哪个组件就检查哪个；显式完整校验仍可在管理页执行。
- 创建 ESP32 工程可选择已安装的 IDF 版本，工程锁定组件与 SDK 精确版本，不自动切换到最新版。
- 升级预览及验证副本保留原工程，实际构建通过后再由用户决定采用；组件版本、器件包版本与 IDE 版本分别管理。

组件库：[MCU StudioX Toolchains](https://github.com/XieJunHui9566/MCU-StudioX-Toolchains)。全量组件的手动分享入口：[百度网盘 MCUStdioX](https://pan.baidu.com/s/5fh5exaJIgC6ThwSS_IdDOA)。请按库中清单区分已公开组件与尚缺材料的本地备份，不把手动分享视为已完成授权审查。

公开库中的 ARM、通用 RISC-V、SDCC、Icarus、PC 及多个 IDF 新组件可并存安装。轻量版遇到旧器件包或工程锁定的组件未公开时，需要手动导入精确版本，或按升级预览建立匹配新器件包/组件的工程副本，不能自动替代。

## 发布验证

发布从审核后提交的干净源码构建，运行基础回归、组件目录与归档检查，并验证两种真实载荷的共同文件和器件包一致性、隔离安装/升级/卸载及桌面启动。Release 附校验和及绑定源码提交的验证记录。具体结果以该记录为准；本轮不进行硬件连接或烧录。

目前安装包未配置产品代码签名证书；SHA-256 用于核对下载完整性。
