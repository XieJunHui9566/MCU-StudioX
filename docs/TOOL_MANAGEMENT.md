# 开发环境组件管理

入口为“工具 → 开发环境组件 → 开发环境组件管理…”，命令面板也能进入。原环境页入口统一转到同一管理页；所选版本的导出、修复和可恢复区操作放入“更多操作”，启用/禁用、删除、完整校验和调试检查显示在列表上方。应用服务位于 `Application/Tools`，Desktop 只呈现报告和调用维护动作。

管理页根背景透明，详情沿用 `ToolSurface` 的主题与媒体透明度；深浅主题、图片与视频背景遵循统一外观资源。刷新列表、打开管理页、启动 IDE 都不对 SDK 做内容哈希；`ToolInventoryService.DescribeAsync` 只读清单，明确的工程校验调用 `VerifyProjectAsync`，只使用 `ProjectDevelopmentComponents` 返回的精确组件需求并核对既有内容锁。构建等实际工具调用也只解析所需版本，进度包含组件 ID 和版本。

## 依赖与空间

只枚举工具 ID/版本层级，逐目录统计文件长度和元数据，不跟随重解析点。空间明确显示为逻辑文件大小，不保证等量物理空间释放；只删除一个硬链接不影响其他链接指向的内容。

依赖检查包括当前工程、最近工程记录、手动登记工程的工程清单与三个已知工具内容锁，已安装器件包的工具要求，以及 CubeMX、LVGL PC、AG32 映射/原生逻辑、RTL 仿真的固定版本。SDK 按工程明确版本保留，不猜测兼容替代。最近工程最多保留 12 条，所以未记录的其他工程必须手动登记。报告列出检查范围；任何登记、最近工程或器件包读取失败都禁用清理，保留原始异常。登记存于独立用户数据目录的 `tool-management-projects.json`。

## 升级与恢复

新版本通过 `.mcutoolchain` 离线归档安装，默认 7z/LZMA2；已有 ZIP 格式的 `.mcutoolchain` 和 `.studioxtools` 继续可导入。完整和轻量 IDE 均自带读写器，无需另装 7-Zip。预览读取身份、组件版本、展开大小和归档 SHA-256；确认后重新核对归档身份，完整校验暂存副本后原子发布。固实包顺序解压，拒绝解码资源超限、路径越界、链接、重复/未索引条目、损坏内容和已有版本覆盖。不执行归档程序，也不修改现有工程、器件包、内容锁、系统 PATH 或安装全局运行时。SDK 迁移应使用匹配的器件定义，不在此页绕过框架校验。

未引用、未占用且不是最新已安装版本的旧版本，可整体移入工具目录的 `.retired/<GUID>/<ID>/<版本>`；管理记录包含原身份、清单指纹和 UTC 时间。移动失败或记录保存失败回退原目录。恢复时重新完整核验内容，拒绝覆盖同版本；保留恢复记录。移入可恢复区仍占磁盘空间。

常规 `RetireAsync` / `PurgeAsync` 继续保护最新和有依赖的版本。用户明确审阅影响后，管理页使用 `RemoveAsync` / `DeleteAsync`，允许移除最新或有依赖的版本；正在占用、身份异常或依赖检查不完整时仍禁止维护。确认后比对完整依赖集合，依赖变化要求重新审阅，不继续执行。永久删除已安装版本先整体移至可恢复区，再复查元数据、路径边界和所有目录条目；移出后取消或失败保留可恢复记录。开始实际删除后不主动取消；文件占用等失败保留管理记录为 `purging`，刷新后可继续删除剩余内容，此时不可恢复。不会清理源码、构建产物、用户数据、独立开发环境组件或其他应用，不改写依赖工程或锁。报告导出只保存本机 JSON。

## 占用互斥

`Foundation/ToolUsageLease` 用当前用户临时目录中的文件共享锁区分使用和维护；租约不写入工具的哈希树，进程崩溃后由操作系统释放。目录身份通过实际 Windows 路径归一化，短路径和目录别名共享租约。

工具校验和 `ProcessRunner` 持有共享租约，GDB/OpenOCD 会话持有到进程退出；安装、离线修复、移出、恢复、永久删除使用独占租约。工具占用列标为 IDE 占用；外部直接启动且不使用租约的程序仍可能造成文件系统占用错误，错误保留并可重试，不自动强杀进程。

## 验证入口

`tools/StudioX.ToolManagementValidation` 的第一个参数是新证据目录，第二个参数是本机 Ninja，仅用于离线工具夹具。验证版本并存、工程/包依赖、跨进程互斥、损坏与越界归档、可恢复移动、永久删除中断重试和硬链接保留；不编译固件或连接设备。

`MCU StudioX.exe --preview-tool-management <新输出目录> <工程>` 只读取实际运行时与工程，按钮状态使用界面数据夹具，检查深浅主题、窄窗口、重复打开、故障状态和帮助入口，不实际维护本机工具。
