## 真实桌面操作

使用 computer-use 操作 IDE 界面（未通过后台注入 UI 状态）：

- 打开串口终端及协议页，点击「离线示例」，列表显示请求、正常响应、异常响应、CRC 错误共四帧。
- 点击正常响应，详情显示寄存器 42 / 4660、UInt16 / Int16、原始字节、接收和计算 CRC。
- 勾选「仅异常」，4 帧筛为 2 帧。
- 在发送框键入 `01 03 00 00 00 02`，点击「补全 Modbus CRC」，得到 `01 03 00 00 00 02 C4 0B`，自动选择 HEX / 无行尾，RX/TX 仍为 0。
