# CH592 器件包与实板连接

## 2026-09-26：FreeRTOS 模板

当前包为 `wch.ch592/0.1.1`，保留 `spl` 裸机模板，新增 CH592D/F/X 的 `spl-freertos`「标准库 + FreeRTOS」。WCH 的 [官方 EVT 清单](https://github.com/openwch/ch592/blob/main/EVT/CH592_List.txt) 明确收录 FreeRTOS、RT-Thread 和 HarmonyOS 移植；本次接入已核实的 FreeRTOS，BLE 使用的 TMOS 不作为完整 RTOS 模板显示。

FreeRTOS 来源为 [openwch/ch592](https://github.com/openwch/ch592/tree/a46e0086f1ffb5e5502703970bff94888e67f4cb/EVT/EXAM/FreeRTOS)，固定提交 `a46e0086f1ffb5e5502703970bff94888e67f4cb`。只获取这套移植的 40 个源文件及原始许可，源归档约 298 KiB；没有下载重复的大型 SDK。每个文件先核对 Git blob 身份，确定性 ZIP SHA-256 为 `ea6eab507a31902917f6e0a4700dcd83f22269a8af388699ad2d7c5a37b27eff`。WCH 移植的 Apache-2.0 声明、内核及配置原始声明保留在源文件及包内 `licenses/`、`vendor/provenance.json`。

模板使用官方 FreeRTOS 启动文件与统一中断入口，官方链接脚本保留其向量段；仍限定 448 KiB 应用 Flash / 26 KiB SRAM，60 MHz PLL。`src/main.c` 是无板级引脚的双任务计数器，`include/FreeRTOSConfig.h` 可编辑，默认 `heap_4`、8 KiB 堆、独立 ISR 栈，软件定时器关闭；不自动初始化 BLE/TMOS。

可复现生成步骤（第二步复用本机 NoneOS SDK）：

```powershell
python tools/WchRtosTemplates.py --fetch-ch592 .artifacts/upstream/ch592-FreeRTOS-a46e0086.zip
python tools/New-Ch592Pack.py --sdk '<MounRiver 的 CH59X/NoneOS>' --rtos-sdk .artifacts/upstream/ch592-FreeRTOS-a46e0086.zip --output artifacts/packs/CH592-0.1.1-verified
```

CH592F 的 FreeRTOS 模板通过真实 WCH GCC 12 离线编译，Flash 占用 5836 字节、RAM 12228 字节。原厂 `CH59x_i2c.c:84` 的既有整数转换警告完整保留；本次不修改无关厂商驱动。新模板不宣称实板运行或 BLE 协议栈验收。以下是此前 `0.1.0` 裸机包与实板连接记录。

`wch.ch592/0.1.0` 面向 CH592D、CH592F、CH592X，使用本机 MounRiver Studio 2 随附的 WCH 官方 CH592 NoneOS SDK、启动文件、标准外设库和 `wch.riscv/1.0.0` 工具集。工程选择应以芯片实际型号为准；CH592 工程和 CH595 工程不能混用。

CH592 的总 Flash 为 512 KiB，其中可用于应用程序的 Code Flash 为 448 KiB，SRAM 为 26 KiB。编译、下载和调试的地址范围按官方 SDK 链接脚本中的应用区限定，不能把 512 KiB 总量当作程序区容量。

CH592F 使用 **PB15→WCH-Link CLK、PB14→DIO**，两端 GND 共地。开发板用自身 USB 供电时不要同时连接 WCH-Link 的 3V3 输出。WeAct Studio V1.0 板背面的 `B15→TCK、B14→TIO` 与 CH592F 一致；板载 BOOT 键下拉 PB22。接线应断电完成，再给开发板正常上电。

调试前，在 WCHISPTool 的 CH59x 页面选择 CH592，以 BOOT 键让芯片进入 USB Boot，搜索设备并执行「开启两线仿真」。显示成功后关闭工具，释放 BOOT，断电重上电正常运行，再连接 WCH-Link 的 RISC-V 模式。IDE 只读核对芯片 ID `0x92`、调试使能和读取权限；受保护或型号不符时拒绝下载。不要在 WCHISP 下载配置中启用代码和数据保护后再期望使用源码调试。

CH592D/F/X 已完成离线建工程、实际编译和调试配置验证。**当前这套 CH592F 实板暂时无法调试**：WCHISP 已识别芯片并显示开启调试接口成功，但 WCH-Link 仍无法建立握手。实机下载和单步调试尚未验证，测量值与失败日志见 实板调试状态（本地记录）。
