# MCU StudioX 0.2.6.12

本次为本地安装升级版本，Windows x64 轻量安装包可覆盖升级 0.2.6LTS，沿用原安装位置，保留独立工具链、用户设置和工程。产品、程序集与文件版本均为 0.2.6.12。

- 接入 IAP15F2K61S2 / Mon51 V2.5 原生调试，在顶部「调试」菜单与工具栏提供入口，快捷键 Ctrl+F5。
- 支持暂停、继续、指令与源码单步、步过、步出、运行到光标、地址及源码断点、条件与命中次数、临时断点和日志点。
- 支持寄存器、只读程序内存、反汇编、经校验的 SDCC CDB 源码映射、监视、局部变量与可验证的调用栈；允许显式修改受支持的 RAM 和寄存器并回读验证。
- 软件断点有原始指令记录与恢复校验；连接调试不自动下载固件。代码区、监控区及调试器占用区域遵循已验证边界。
- STC 下载完成后显示成功反馈，提供原始下载日志入口。
- 器件包回归保留每次导入的统计和原始失败诊断，便于排查间歇性加载错误。
- 器件包导入与插件更新的原子目录移动对 Windows 短暂共享冲突进行有界重试；持续占用仍报告原始错误，取消保留原目录。
- Mon51 连接失败或取消后可直接重试，保留工程调试偏好；零接收超时与应答校验失败分别报告，连接日志记录具体串口参数。

详细操作与芯片支持边界见 [STC Mon51 调试界面](STC-MON51-UI.md)。其他 STC 型号和监控版本尚不视为已通过实板验证。

本地安装包记录实际工作区来源；此次制作安装包不包含 Git 提交、推送或 GitHub 发布。
