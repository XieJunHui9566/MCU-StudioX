# MCU StudioX 0.2.6.15 · 2026-11-03 修订

Windows x64 轻量安装版、完整安装版和对应源码。产品版本保持 0.2.6.15，使用独立的日期修订标签，不覆盖旧标签或旧安装包。

## 本轮更新

- 集成 MX251 0.0170（测试）SDK：统一编译器与优化数学库，保留独立 CMake/Ninja 入口。IDE 按 SDK 契约和内容清单接入，项目继续锁定组件版本。
- AI8051U-32bit 提供寄存器、库函数模板；STC32G 提供寄存器模板。器件包 0.2.171 修正编辑器的宿主 ABI 误报，真实目标编译的宽度断言保持启用。
- AI8051U 下载恢复串口 ISP、芯片原生 USB、AI8H2K12G USB 下载桥选择，统一进入下载设置。串口和原生 USB 已完成抓包对应的离线协议回放；本次发行不增加实板验收结论。
- STC 下载设置、串口监控与 Mon51 启动流程更新；SDCC 工程增加内存模型和 RAM 参数配置。
- PIC 下载与调试服务、构建产物管理、源码登记、编辑比较和插件错误处理更新。PIC 的专有 XC8/IPE/MDB 由用户从厂商取得，公开包不附带这些工具。
- 模板新生成的无限循环使用 `while (1)`；普通构建复用最新产物目录，继续保护正在下载或调试的固件。

## 两种安装包

轻量版包含同一套自包含 IDE、Git、语言服务、插件宿主和当前公开器件包。完整版本另外预装本次组件清单所列开发工具。受限厂商工具、本机许可证、账户数据及用户工程不在公开安装包内。

完整安装器的 EXE 与全部同名分卷 BIN 放在同一目录，运行 EXE。覆盖安装须关闭 IDE，并沿用原安装位置；安装器保留工程、用户设置及已安装的独立组件。产品未配置代码签名，下载后可用随附 SHA-256 清单核对文件。

## MX251 使用

完整版本预装 `studiox.mx251/0.0.170` 和 `studiox.cmake/4.4.0`；轻量版本可从开发环境组件入口获取。新建工程选择 AI8051U-34K64 或 STC32G12K128 及相应模板。原工程不会自动改写，工程使用的准确版本与指纹继续保留。

源码与独立工具链：https://github.com/XieJunHui9566/MX251

组件：https://github.com/XieJunHui9566/MCU-StudioX-Toolchains

器件包：https://github.com/XieJunHui9566/MCU-StudioX-MCUPacks

MX251 仍为体验版本。指定模板离线编译、协议回放、历史实板测试及编译器性能统计分别记录；没有将可编译或协议 ACK 表述为所有工程的性能或实板正确性通过。具体发行验证和组件身份见本 Release 附件。
