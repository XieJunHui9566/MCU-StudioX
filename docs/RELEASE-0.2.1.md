# MCU StudioX 0.2.1 预览版

此版本把 0.2.0 安装包构建之后完成的 IDE 更新重新封装为 Windows x64 安装包。项目仍处于开发预览阶段；各器件的实板验证范围以对应文档为准。

## 本次更新

- 新增 Git 图谱及 GitHub 登录、远程同步和 Pull Request 协作界面。
- 扩展 STC8 的 SDCC 编译和串口 ISP 下载配置，支持工程中的 Flash 容量与时钟选项。
- 加入 CH592、CH595 器件包和相关工程模板；CH592F 的实板调试目前标记为未验收。
- 汇总近期 STM32、AG32、WCH、PY32、GD32 和 RP2350 的工程与调试适配更新。

## 安装与限制

运行 `MCU-StudioX-0.2.1-win-x64-Setup.exe`。安装器为 Windows x64 自包含预览版，尚未进行代码签名。安装前请保存工程并关闭正在运行的 IDE。

内置器件包会随安装器提供，但不同型号的编译、下载和调试验证程度不同。请查看对应器件文档；特别是 CH592F 的 WCH-Link 实板握手尚未成功，不能视为实板调试已支持。

本地构建产物的生成不等于已获公开再分发许可。公开发布安装器前，须完成内置第三方开发环境组件和 SDK 的许可材料核查；当前审核状态见 [安装器说明](INSTALLER.md)及 `runtime/THIRD-PARTY-NOTICES.txt`。
