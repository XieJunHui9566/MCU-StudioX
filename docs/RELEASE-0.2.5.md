# MCU StudioX 0.2.5 预览版

日期：2026-09-27。发行包含 Windows x64 自包含便携目录、完整安装包及 IDE 源码。产品版本为 0.2.5，器件包和开发环境组件继续使用各自锁定版本。

## 更新

- 接入共享的 ESP-IDF 5.5.4，支持 ESP32/WROOM、ESP32-P4、ESP32-S3、ESP32-C3/C5/C6；ESP8266 使用独立 RTOS SDK 3.4。新建模板复用 SDK 官方 Hello World 和 FreeRTOS 示例。
- 「器件与模板」新增 ESP 模组与存储配置，提供七个目标的 125 个已核实规格预设与自定义参数。覆盖 Flash 容量/模式/频率、PSRAM 模式/声明容量、P4 修订系列及经典 ESP32 单双核。完整料号保留天线、温度和电压差异说明。
- 模组选择保存为独立工程配置，构建使用受控的 SDK 配置覆盖，保留用户的 CMake、默认配置与自定义配置。精简模板启用 PSRAM 时加载相应 SDK 组件，保留用户组件根；配置改变后旧构建凭据失效。
- ESP 串口下载使用原生多映像布局，按项目保存 COM 与速率；修复已选串口不显示和厂商图标问题。资源面板默认显示 Flash/RAM 总览，可展开原始分组。
- `project_info.espressifModule` 向内置 Agent 和外部 MCP 返回所选模组参数，芯片目标与模组规格分别记录。
- LVGL 8.3.x PC 预览使用内置 Windows GCC/G++ 在独立窗口运行实际 UI。新增自定义 UI 配置向导，扫描多层目录中的库、入口、配置头、字体、图片及运行时资源，并保留真实编译诊断。
- LVGL 资源报告分别记录目标 ELF/MAP 静态占用、PC LVGL 堆和观测峰值、绘制缓冲预算、PC FPS 与可选显示传输模型；未知目标占用保持未知。
- 修复 AG32 `.ve` 高亮正则产生零长度匹配并导致界面崩溃的问题。高亮失败时安全退回纯文本并保留诊断，不改写时钟或引脚配置。
- 拆分 AI 会话、模型协议、进度、授权、用量、外部文件事务、编辑器同步和模拟设备职责；公开类型按职责分文件，统一源码排版与中文约束注释。

## 验证范围

产品解决方案构建要求零警告、零错误。模组配置已完成全部预设的持久化与参数边界验证，以及实际 MCP 会话和 WPF 控件验证。

| 内容 | 验证 |
| --- | --- |
| ESP32-S3 N8R8 / N16R8 | 真实原生编译、完整多映像布局、配置保留及旧凭据失效 |
| ESP32-S3 WROOM-2 | Octal Flash / Octal PSRAM 原生配置 |
| ESP32-C5 | Quad PSRAM 真实编译，保留显式用户组件根 |
| ESP32-P4 | 新旧修订系列、HEX PSRAM 原生配置 |
| 经典 ESP32 | SOLO 单核与 WROOM 双核及容量选择原生配置 |
| ESP8266 | 独立 SDK 的 Flash 配置 |
| 自定义 SDKCONFIG | 不同日志选项保留、隐藏基础配置和记录的哈希、恢复实际路径、首次未知路径明确拒绝 |
| 界面与 MCP | 七个目标、深浅主题、窄窗口、保存/重载/撤销、实时配置编辑器刷新及真实客户端读取 |

上述是软件配置、编译与离线界面验证，不代表全部模组经过实机验收。LVGL PC FPS 和宿主内存不能代替 MCU 性能、任务栈或板级显示总线测量；既有硬件验收范围见对应器件文档。

## 发布与隐私

GitHub 本轮发布 IDE 源码、器件配方、验证工具和许可材料。API 密钥、账号凭据、用户配置、对话历史、用户工程、原始硬件日志、Flash 备份和本地构建资源不进入源码仓库。

完整二进制已在本机打包，包含已锁定 SDK、开发环境组件、标准头文件与库、语言服务、Git、MCP/插件宿主和当前器件包；用户数据仍保存在独立的当前用户目录。安装器、便携目录与逐文件 SHA-256 采用同一产品版本。公开分发仍需补齐供应商对应源码与再分发材料，尤其 AGM 修改版开发环境组件，依照安装与分发说明执行；本轮不将完整二进制作为公开 GitHub 附件。
