# IAP15L2K61S2 / LQFP44 外设核验与初始化范围

核验日期：2026-10-22。适用配套器件包与插件 0.1.4、profile 3.0.0、裸机 C / SDCC 4.5.0。IDE 产品版本未改变，本轮未修改通用 IDE 实现，也未连接硬件。

## 资料与准确型号

- [STC15 series MCU Data Sheet，2015-10-10](https://www.stcmicro.com/datasheet/STC15F2K60S2-en.pdf)，封面列出 IAP15L2K61S2；第 15–24 页界定 STC15F/L2K60S2 系列、LQFP44 引脚及容量。PDF SHA-256：`c1df3cdb156465acc3f1d07b283b0c599d33cc170a7946a8cb9330aa84273801`。下列页码为 PDF 物理页码，也与印刷页码一致。
- [厂商中文系列选型页](https://stcmicro.com/cn/stc/stc15f2k60s2.html)，确认 3 个普通定时器、2 路串口、3 路 PCA、8 路 ADC、5 路外部中断；其 SPI 表头标明“仅有主机模式”，且说明 C 版 MCLKO 只能输出内部 IRC。
- AiCube 6.96V-plus 的 STC15 SDCC 头文件只核对寄存器符号和地址，不以系列共用头文件证明准确型号具有某外设。输入文件、摘要和模板摘要保存在插件 `Assets/provenance.json`；厂商原始程序和 PDF 不装入插件或器件包。

两个串口使用不同计数器时可用不同波特率；共用 Timer2 时必须波特率、分频都相同，仅初始化一次 T2。被串口占用的定时器不可同时配置为普通定时器。PCA 使用 T0 溢出时要求 T0 已配置，运行时应用还须启动 T0。

定时器计数与输出引脚分别为 T0=P3.4/T0CLKO=P3.5、T1=P3.5/T1CLKO=P3.4、T2=P3.1/T2CLKO=P3.0。PCA 路由及 UART、SPI、ADC、INT、GPIO 同时进入引脚占用检查。选中的外设参数和时钟树由同一份配置推导，文件中两者不一致时拒绝生成。

## 资料分歧和范围

旧英文手册第 797 页描述 SPI 主从功能，而厂商中文选型页明确限制本系列仅主机。缺少准确硅版本证据和实板验证时，本版只开放主机，不用共用 SPCTL.MSTR 位的存在推断从机可用。

ADC 第 664 页明确使用未经过 CLK_DIV 的内部 IRC。CPU 选择外部晶振时，插件显示 ADC 内部 IRC 校准值未声明，不把晶振或 SYSCLK 当作 ADC 时钟。手册第 679 页示例在 ADC 上电后进行软件延时，未给出统一最短稳定时间；本生成器建议业务预留 10 ms 并按电路验证，提供等待常量与说明，不生成读取循环。唤醒定时器为非精密 RC，显示计数与名义周期，不承诺精确毫秒。

该型号没有本次可核实的独立比较器、I²C、DMA、Timer3/4、UART3/4 或 W4K 系列的六通道增强 PWM，因此不借用系列共用手册/头文件开放它们。PCA 的 PWM 不是模拟 DAC；本版提供 8 位硬件 PWM，未生成需要业务 ISR 的软件高分辨率 PWM。

本轮补齐外设初始化入口，普通计时器只提供 16 位自动重装，串口只提供 8N1。13 位/8 位计时模式、UART 9 位/同步工作模式、其它 PWM 分辨率仍未实现；界面明确标注当前模式。除用户另行要求的可选 `USART1_printf` / `USART2_printf` 外，读写、ISR、运行中调度与内存区域规划由用户编写。选项字节、复位门限、读保护、加密和 ISP 下载策略不由初始化代码修改。

串口 printf 的开关独立、默认关闭，参数保存在现有 UART 配置的可选 `printfEnabled` 中。函数使用当前锁定 SDCC 的格式化库和对应串口的 TX 完成标志，返回字符数或 `-1`，不截断到固定输出缓冲区；有界轮询超时后不会覆盖尚未完成的 TX 字节。它只适用于主循环，不能与串口 ISR 或其它格式化调用并发；格式范围、使用示例和浮点限制见[插件说明](../plugins/StudioX.StcConfigurator/README.md#串口-printf)。这项维护不改变时钟、引脚资料、器件包或 IDE 源码。

## 工程兼容和验证

时钟树与封装图共用 IDE 通用视口：左键拖动、指针位置滚轮缩放、缩放滑块和居中适配。时钟视图可缩放到 15%–250%，首次打开显示全图；切换页面和更新参数保留平移与缩放。图内的可编辑频率和下拉框保留自身的鼠标操作。

基础资料属于不可变模板，不能在现有 2.2.0 文件中塞入未声明的新外设。插件同时识别旧包 0.1.3 / profile 2.2.0 和新包 0.1.4 / profile 3.0.0。旧工程保持原能力和来源摘要；新工程使用扩展模板。预览升级采用独立副本，记录原配置摘要，保留原工程与用户源码，生成仍检查文件所有权。

专项验证分别覆盖旧路径与扩展路径：准确能力、资源冲突回滚、锁定、共用 T2、T1/T2 两种分频、Timer2 与外部计数、PCA/PWM 边界、ADC 时钟独立性、外部中断触发限制、WKT 边界、P5.4 复用、保存重开、模块清理、真实隔离插件宿主及 SDCC 编译链接。构建日志、编译矩阵和维护回归结果随本次验收证据保留。软件验证不等于实板验收。

printf 专项还执行真实 SDCC 格式化固件，使用随工具链提供的 uCsim C52 模拟器，以寄存器夹具提供两路 TX 完成标志，核对整数/字符串/宽度/精度、长输出、返回值、错误与超时重试。此夹具不模拟 STC 的波特率硬件或实际 UART 电气时序。隔离插件宿主验证生成/移除函数及 main/CMake 自动接入后的分模块编译。
