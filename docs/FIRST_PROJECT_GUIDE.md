# 第一个工程完整引导

欢迎页“第一个工程引导”和帮助菜单提供同一个可关闭、可继续的分步页面。首次启动且没有最近工程、没有恢复的工程时自动打开；“结束引导”写入独立用户目录中的 `first-project-guide.json`，不改工程文件。以后仍可手动打开。

## 七个步骤

1. 准备：确认完整料号、框架、器件包和 IDE 管理的开发环境组件版本。
2. 创建或打开：进入实际器件/模板选择页，或打开已有工程；不替用户猜目标。
3. 快速健康检查：工程锁、工具、SDK 与构建配置，提供现有修复入口。
4. 编辑与保存：打开入口源码，解释新源文件登记、Ctrl+S、保存全部。
5. 首次编译：调用正常的 F7 流程，包括保存和编译前检查，完整原始输出。
6. 查看结果：本次编译结论、产物路径与占用说明。
7. 运行与调试：可选的实板核对、备份、下载、断点、串口说明。

每步显示操作方法、预期界面、当前工程证据以及相关离线帮助。步骤可自由回看；点击下一步不会伪造完成标记。切换或关闭工程清除本次保存、检查、编译证据，源码修改清除编译结果。教程不把历史固件当作新源码编译成功。

## 框架差异

ESP-IDF 保留原生构建与错误帮助，明确 target 和 Flash/PSRAM 需要实际模组信息。MicroPython 显示脚本步骤，不调用原生固件编译。Zephyr 保留实验支持说明，不显示已验证原生构建。下载和设备连接都从正常入口明确启动；引导本身不自动访问硬件。

## 性能与数据

自动入口只读最近工程和一个小偏好文件，不导入器件包、不扫描或校验 SDK。引导不可见时不重新构造列表，避免影响大工程编辑。领域内容与用户偏好由 Application 服务管理，Desktop 只组合已有应用服务和工作台入口。

准备步骤现在直达“准备工程开发环境组件”；创建后可再次进入，按精确版本查看缺失项、安装预览、继续下载及离线导入。详见 [准备工程开发环境组件](ON_DEMAND_TOOLS.md)。
