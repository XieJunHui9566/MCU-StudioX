# 离线帮助中心

“帮助 → 快速开始”和“帮助手册…”打开同一个可检索的帮助标签，F1 不依赖当前工程。快捷键速查及故障处理指南直接定位相应正文；原始故障页保留诊断，并按具体错误提供完整手册入口。

手册有 32 个主题、6 个分类，每篇包含明确入口、操作步骤、结果说明与排错方法。范围涵盖工程与器件包、编辑与 CMake、ESP-IDF、MicroPython、构建与参数、下载与调试、FreeRTOS、串口与绘图、插件及程序员助手、工具修复、Git、AI、外观、LVGL、故障恢复与快捷键。手册可以离线阅读，按标题、关键词、摘要和正文搜索；空格分隔的多个词需全部命中。支持复制本篇和关联阅读。

内容位于 `src/StudioX.Application/Help/Articles/*.md`，索引位于同目录上层的 `index.json`。文章随 Application 程序集嵌入，安装后不依赖源码目录或在线地址。新增文章时同步提供唯一 ID、分类、标题、摘要、检索关键词和有效关联 ID；正文首行与索引标题一致。Application 提供内容和检索，Desktop 负责只读文本呈现，均不触发构建或设备动作。

WPF 渲染支持标题、粗体、行内代码、列表、代码块和表格。窄窗口自动收起目录，仍可用目录按钮打开；正文使用完整可滚动区域和随主题更新的配色。

验证：`MCU StudioX.exe --preview-help <新的输出目录>`。使用隔离用户数据、不打开工程、不访问硬件。检查正文完整性、所有文章渲染、全文检索、类别过滤、快捷键、关闭后重开、空结果、深浅主题、窄窗口和快捷键表格，保存截图与 `help-result.json`。
