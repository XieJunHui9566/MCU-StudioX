# 2026-10-30 源码风格与安全检查

本次交付为 MCU StudioX 源码更新，产品版本保持 0.2.6.15，不制作或发布安装包，不替换用户工具链，不连接或烧录硬件。

## 范围

风格检查覆盖第一方 `src`、`tools`、`examples`、`plugins` 中的 C#、XAML 和构建 XML，以及维护脚本、选定的 C/H 模板。厂商 SDK、许可证、生成内容、运行时和编译产物不批量改写。RT51 的 SDCC 汇编端口保留原有布局，按其临界区、固定容量和上下文约束人工核对；本次不重新宣称固件实板验收。

MX251 尚未达到固定完整工程逐项不大于 Keil C251 110% 的体积和运行时间门槛。编译器候选、性能研究、冻结成本模型负例和实板备份保留本地。本仓库只公开 IDE 适配、独立构建契约和通用构建模块；没有发布候选编译器或授予 LST 资格。完整 SDK 仍需单独审核的编译器、运行库及来源输入。

## 修正

- 统一导入顺序、无用引用、公开类型分文件和第一方插件排版。拆分共享 ISP DTO 后同步 Engine 的显式源码链接。
- C# 格式器验证可执行 token 并恢复字面量；PowerShell 格式器兼容混合换行，并逐一恢复字符串和 here-string，再核对可执行 token。Python 比较 AST，C/H 比较 token。
- Windows 系统 DLL 的 P/Invoke 显式限定 `System32` 搜索位置，并启用 CA5392 门禁。
- 自有 HTTP 处理器启用证书吊销检查。自定义 MCP 使用禁止自动重定向、禁用 Cookie 的专属 HTTP 客户端，生命周期由传输层管理；回归覆盖重定向时不访问第二个端点。
- 默认构建启用 SDK 全部安全规则和 NuGet 直接及传递依赖审计。四个 ZIP 路径告警经逐项核对，均已通过 `PathBoundary.Resolve` 净化；只在对应方法记录窄范围误报说明。算术测试中的固定种子随机数不是安全用途，单独说明。
- 修复 `.gitignore` 漏收发布目录验签公钥的问题；仅允许这一份 `BEGIN PUBLIC KEY` 文件，私钥规则继续生效。
- AI 协议、凭据、技能导入及自定义 MCP 离线回归纳入基础维护门禁。
- CI 仅上传检查报告、日志和界面截图，不上传测试过程生成的程序、插件或器件包。
- 干净 CI 主机发现格式检查隐式依赖本机 `rg`。源码枚举改为复用内置 .NET 格式工具的目录边界，不要求全局安装额外命令。
- 清除内置检索入口对全局 Node/QMD 的执行依赖及环境继承。保留 `project_qmd_search` 工具名，改为内置 C# BM25：只读已净化的有界源码快照，支持复用、修改/删除失效、缓存篡改重建、词频排序和有界片段；不执行工程内容、模型或外部程序。

## 检查入口

```powershell
./tools/Test-Regression.ps1 -OutputDirectory <新的隔离目录> -MaintenanceAreas baseline
./tools/Format-FirstPartySources.ps1 -PrepareTools  # 首次准备固定版本和 SHA-256 的格式器
./tools/Format-FirstPartySources.ps1
dotnet list StudioX.slnx package --vulnerable --include-transitive --format json
gitleaks dir . --redact=100 --report-format json --report-path <仓库外的报告路径>
```

基础回归包括 Release 构建、安全边界、C#/XML 格式、MCP、AI、架构、工程迁移/同步/登记、插件隔离、包保留和桌面离线界面。使用空运行时目录，不安装厂商 SDK，也不调用付费模型。详细原始日志保留在维护者本机隔离证据目录；发布树不包含凭据、用户配置和硬件备份。

Gitleaks 的公钥 SHA-256 指纹误报仅在对应常量行标记，不忽略整个文件或关闭通用密钥规则。静态分析、依赖数据库和离线回归不能证明不存在任何未知漏洞，也不替代器件实板验收。
