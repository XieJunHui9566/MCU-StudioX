# 串口绘图

独立于“串口终端”的工具，通过左侧波形图标、工具菜单或欢迎页“串口绘图”打开。不需要打开工程。图表沿用工作台透明背景。

## 数据格式

默认每行是一组采样值，逗号区分通道，例如固件连续输出：

```text
4095,1024
4090,1030
4080,1042
```

界面上的“通道分隔符”和“每组结束符”均可自定义，按字面值匹配，支持多字符及 `\r`、`\n`、`\t`、`\\` 转义。例如：

| 数据 | 通道分隔符 | 每组结束符 |
|---|---|---|
| `4095,1024` 后换行 | `,` | `\n` |
| `4095;1024` 后 CRLF | `;` | `\r\n` |
| `4095\t1024`（实际制表符）后换行 | `\t` | `\n` |
| `4095||1024<end>` | `||` | `<end>` |

数字使用英文小数点，支持负数、小数与科学计数。接收 UTF-8 数字文本，默认 LF 也兼容 CRLF；不剥离 ANSI、不读取 HEX 二进制值。首个有效数据组决定通道数量（1–16 路）；后续数量不一致、空字段、无效数字、NaN / Infinity 或绝对值大于 1e100 均计为错误并断开曲线，不把坏数据当作 0。单组最多 4096 字符，超长后丢弃到下一个结束符再恢复。未收到完整组结束符时不会绘制半组。

先设置端口、波特率、数据位、校验位、停止位、流控，再点“开始采集”。连接期间格式锁定，停止后修改并重新连接，新会话清空旧数据。DTR / RTS 默认不拉高且不持久化高电平；硬件流控时 RTS 由驱动管理。

实物串口首次连接、重新连接时，先丢弃到第一个组结束符，再从下一组完整数据确定通道数。这避免连续输出时从半行接入而误识别通道。首段即使碰巧完整也不计入采集；需要保留第一组的发送方应在数据前先发一个组结束符。

同一串口只能有一个拥有者。串口终端占用该端口时，先断开终端再启动绘图；可以同时使用不同端口。关闭绘图标签、停止采集或退出 IDE 会释放会话，保留图表快照至下一次采集 / 清空。

## 时间与交互

- **采样周期 0**：使用电脑接收的单调时钟，相对当前采集起点计秒。同一个 USB 数据块内的多组可能共享时间戳，不能据此推断设备的精确采样时间。
- **采样周期大于 0**：按指定周期排列各组，例如设备每 10 ms 发一组，就填写 `10`。格式错误占据一个采样位置；USB 包丢失时无法推断丢了多少组，会断开曲线，丢失期间的时间长度未知。这不是硬件时间戳。
- 图内或时间轴上 **Ctrl＋滚轮**：围绕鼠标位置缩放时间。
- 左侧数值轴上 **Ctrl＋滚轮**，或图内 **Ctrl＋Shift＋滚轮**：缩放值域。
- 普通滚轮：沿时间轴平移；拖动：横纵平移；双击：复位。
- “时间＋/－”“数值＋/－”也可分别缩放。手动操作取消相应自动跟随；勾选“跟随最新 / 自动值域”恢复。
- 彩色通道栏显示每路最新值，复选框隐藏 / 显示曲线。鼠标移入图中显示最近采样点的时间和前四个可见通道值。
- “暂停显示”冻结快照，后台继续接收；“继续显示”更新至当前缓存。“清空”重置数据、计数和时间起点，并在下一组边界恢复。
- “导出 CSV”保存当前显示快照，包含时间、断段编号和所有通道；暂停时导出的是冻结快照。注释注明时钟来源，演示数据另外标记 `SIMULATED`。
- “演示曲线”生成三路示例，不连接任何硬件，使用同一分帧 / 解析 / 会话管线，始终显示演示身份。

## 实现与边界

Application/SerialPlot 管理独立会话、增量 UTF-8 解码、采样历史、CSV 和偏好；Desktop 不直接打开串口。沿用 DeviceHub 单所有者约束。后台消费 2048 包有界订阅，丢包计数与帧序号共同检测缺口，失步后等待下一组边界，禁止前后半组误拼。串口驱动错误保留原始诊断。

最多保留最近 **20000 组**，淘汰数可见；不是无限时长记录器。图表每 100 ms 取一次快照，按像素桶保留首末点与极值、保持原始顺序和断段，避免高密度曲线丢掉短脉冲。设置文件在 `%LOCALAPPDATA%\MCUStudioX\serial-plot.json`，与工程和终端设置分开。
