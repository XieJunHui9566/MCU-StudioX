# MCU StudioX 0.2.6.14

2026-10-13。发布 Windows x64 轻量安装包、外观工作室 `1.1.0` 独立插件及同一提交的源码 ZIP，作为预发布版本提供。IDE 产品与 Windows 文件版本均保持 `0.2.6.14`，不替换现有 LTS 发行。下载入口为 [v0.2.6.14](https://github.com/XieJunHui9566/MCU-StudioX/releases/tag/v0.2.6.14)。

## 外观工作室与字体乱码修复

随包提供 `studiox.appearance-studio / 1.1.0`。插件支持六组纯色配色，以及日奈紫夜、月白、暮光三套氛围环境；三套环境共用一张空校园紫夜 PNG，不含人物。图像由 imagegen 生成，不是官方游戏素材，来源说明和生成提示词随插件保留。

可选择本机已安装的界面/代码字体、字号及代码粗体/斜体，先预览再显式应用。符号/图标字体按实际字形覆盖过滤；已保存的不可读字体恢复为可读文字字体，保留其它外观设置。主题是受校验的数据，不执行任意 XAML，用户插件仍在独立宿主运行。首次使用需在插件管理中启用。

氛围环境使用独立图层和用户数据副本；有动态壁纸时自动淡化叠加，切换主题不重开媒体、不重置播放位置。视频循环、最小化/失焦暂停和不透明工作区继续使用既有流程。

## 最近工程右键菜单

欢迎页“最近的工程”提供“在资源管理器中打开所在位置”“从最近列表移除”“删除工程…”。从列表移除保留磁盘文件；删除弹窗显示工程名和完整路径，默认取消。删除调用 Windows 回收站，系统无法回收时仍可取消，不自动降级为直接递归删除。

应用服务重新核对最近记录与 `.studiox/project.json` 标记，拒绝当前工程及其父子目录、系统/IDE/运行时/用户数据、目录根和链接路径。重复名称按完整路径区分，尾部目录分隔符不会产生重复记录。原始失败诊断保留到 IDE 日志。

## 打包与验证

源码在独立发行 worktree 整理，不覆盖原开发工作区的未提交改动。发布流程要求基础/编辑回归、安装器与发布目录绑定相同的干净提交。最终检查结果、源码提交、安装器 SHA-256 与大小以 Release 附件 `artifact-record.json`、`SHA256SUMS.txt` 和验证记录为准；没有通过的检查不会标记为完成。

本机此前完成 32 项维护回归、37 项启动/工程检查、11 项最近工程真实 WPF 检查，以及外观目录与视频播放专项验收；公开发行按干净提交重新构建和验证。安装验收覆盖首次安装、升级、同版本修复、版本降级/运行中保护、中文空格路径和卸载数据保留。本轮不连接、下载或调试硬件。

轻量版保留 IDE、71 个器件包、内置 Git、语言服务及插件宿主，不捆绑 MCU/HDL/PC 开发环境组件。已有工具、工程和用户设置在覆盖安装时继续保留；按工程需要从开发环境组件库获取或手动导入。普通用户无需全局 .NET 或修改系统 PATH。安装规则见 [安装器说明](INSTALLER.md)。
