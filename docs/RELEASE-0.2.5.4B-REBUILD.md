## 本次包含

- **代码模板**：保存常用代码或编辑器选区，按名称和缩写搜索、预览并插入；支持用户级和工程级模板、变量填写、当前缩进、光标位置和一次撤销。通过工具菜单、`Ctrl+Alt+T` 或 `Ctrl+Space` 补全使用。模板在独立用户目录或工程 `.studiox` 目录存储。
- **外设寄存器与 SVD**：导入并核对器件身份，展示寄存器、位域和访问属性；实际读取、修改入口绑定当前暂停的调试会话，过期状态失效，不自动连接硬件。
- **ESP-IDF 故障分析**：使用工程 ELF 和工程锁定的解码工具分析已有 Core Dump，保留原始诊断、符号身份及来源证据；缺少对应工具时提示准备，不使用系统工具猜测替代。
- **工程工具准备**：展示精确版本、缺失组件、来源、空间预算和准备结果，组件下载支持停止与继续；保持工程工具锁定。
- **帮助与验证**：补充代码模板、外设寄存器、故障分析和工具准备说明；统一发布记录绑定源码提交、回归结果与安装包校验值。
- **清理后的构建**：插件验证直接引用源码项目，消除对旧中间编译目录的依赖。

## 安装

下载完整 `MCU-StudioX-0.2.5.4B-win-x64-Setup.exe`，关闭 IDE 后运行，沿用原安装目录。安装保留用户偏好、恢复草稿、用户模板和工程；不修改系统 PATH，不安装全局语言环境或调试器驱动。

完整安装包沿用已核对的内置工具集和器件包。ESP-IDF Core Dump 需要对应的 GDB 工具角色；仅安装 SDK 不表示解码工具已齐备，缺失时使用工具准备入口。产品程序集更新与工程锁定工具的版本分别管理。
