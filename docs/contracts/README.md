# MCU 图形化配置契约资料

状态：待实现的 v1 草案。这里是数据标准和结构示例，没有产品实现、插件二进制或真实器件包。

| 文件 | 用途 |
| --- | --- |
| [主标准](../GRAPHICAL_CONFIGURATION.md) | 文件、模板/工程关联、来源与摘要、配置/生成生命周期、迁移和验收要求 |
| [插件契约](../GRAPHICAL_CONFIGURATION_PLUGIN.md) | 准确支持组合、调用上下文、视图/动作、生成计划、保存恢复和生命周期 |
| [公共 Schema](mcuconfig-v1.schema.json) | Draft 2020-12 结构约束，公共对象拒绝未知字段 |
| [结构示例](examples/README.md) | 虚构 DEMO4 的模板与工程副本，以及 profile 叠加 Schema |

Schema 只执行结构约束；重复 JSON 属性、全局数值/深度/字节上限、ID 唯一性、引用、来源、电气规则、路径链接和文件事务另按主标准检查。各 profile 必须约束所有扩展数据，不得把公共 Schema 的扩展点当作免校验区域。

后续调整公共结构时，必须同步检查主标准、插件契约、Schema、样例和兼容说明。不得仅修改某份示例就宣称支持新能力。产品版本、现有包格式、插件 API 和 SDK 的实际实现状态各自独立。
