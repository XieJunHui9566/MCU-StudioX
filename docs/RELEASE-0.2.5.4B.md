# MCU StudioX 0.2.5.4B

本次更新提供从首次建工程到连接调试、故障分析和组件维护的完整入口，并改善大工程和 ESP-IDF 打开体验。产品版本为 **0.2.5.4B**，Windows 文件与程序集版本保持 **0.2.5.4**；修订字母参与安装器升级顺序，可覆盖升级 0.2.5.4A。

## 主要变化

- **首次工程引导**：器件与模板选择、工程创建、健康检查、编辑保存、首次编译、查看结果及运行调试七步，跟随当前工程证据，不伪造完成标记。
- **大工程性能**：异步文件树、快开扫描复用和文件列表虚拟化；ESP-IDF 打开时的 SDK 自检及统计在后台执行，可取消，减少主界面停顿。
- **调试连接向导**：明确普通附加或受支持的复位连接，显示探针、目标、ELF、只读固件校验和暂停阶段；取消等待清理，退出恢复有明确证据标记。
- **故障工作台**：暂停 Cortex-M3/M4/M7 的 CFSR/HFSR/MMFAR/BFAR、调用栈证据，ESP Panic/Backtrace 日志及离线 Core Dump 文件解析入口；匹配工程 ELF 的离线地址定位、报告导入导出。
- **构建历史对比**：保留最近 20 次成功快照，对比 Flash/RAM 静态占用、MAP 输入段/符号/文件和 Ninja 编译步骤耗时；过期源码或 ELF 拒绝作为当前结果。
- **调试与插件**：API 3 只读暂停快照面板自动刷新；继续运行、停止、停用或切换工程时撤销旧结果。插件管理支持搜索、能力筛选和直接入口。
- **软件与组件分发**：本地/HTTPS 目录、来源和许可证、明确选择的 RSA 公钥签名校验、下载大小/哈希及磁盘预览；工具精确版本并存，插件更新备份与回退并重新信任，CMake/ESP-IDF 源码组件锁定与回退。
- **发行配置与帮助**：发布脚本支持基础版和完整版，默认保持完整版；新增五篇离线操作说明，总计 37 篇。

## 本次分发

Release 提供 Windows x64 自包含完整版安装包、对应源码 ZIP、SHA-256、验证摘要、使用说明及离线插件/组件目录示例。安装包不自动启用用户插件，不改变全局 PATH，不迁移工程工具锁定。组件和工具安装均由用户明确操作触发。程序员助手插件继续独立分发。

## 验证与适用范围

功能开发阶段通过 54 项去重服务检查、17 项页面检查及 42 项调试插件回归。独立 STM32F407ZG HAL 工程两次实际编译，组件参与链接，Flash 静态占用 1,480 → 1,504 字节；离线 GDB 地址定位和过期源码拒绝通过。发行版本重新编译并执行隔离安装/升级/修复、完整性和自包含界面检查，结果以 Release 附带的 validation-summary.json 为准。

本轮发行不连接或烧录硬件。先前 F407 连接只确认识别和退出恢复，没有确认板上固件与测试 ELF 匹配，不能表述为源码单步验收。ESP Core Dump 已接入明确文件的离线 CLI，但真实故障转储样本仍待验收。公共在线分发目录、发布者签名身份和产品代码签名尚未配置；离线示例的发布者自述与哈希不等于数字身份认证。

MAP 显示链接后的静态占用，不包含运行期栈/堆峰值；并行 Ninja 步骤耗时不能相加当作总时间。组件服务不把 ESP8266 RTOS SDK、Zephyr 或 MicroPython 静默当作普通 CMake 工程。
