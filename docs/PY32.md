## 来源与重建

资料来自 [普冉官网下载页](https://www.puyasemi.com/download.html) 公布的固件库/DFP；生成用的 Git 仓库是 [OpenPuya 社区镜像](https://github.com/OpenPuya)，**不是普冉官方 GitHub 组织**。`tools/New-PuyaPacks.py` 将六份社区镜像固定到指定 commit，复制厂商原始版权/许可证，并把镜像 commit、DFP SHA-256、选用的启动文件/链接布局、SDK 文件 SHA-256 记录到每个包的 `provenance.json`。从固定来源重建不需联网。

F002A/F003/F030 共用 `PY32F0xx_Firmware`，但输出三个独立器件包。F040/F071/F072 的 HAL 示例 `system.c` 依赖仅在 HAL RCC 头中定义的宏；对应厂商 `Example_LL/WWDG/WWDG_WINDOW` 的 `system.c` 使用芯片寄存器常量，适用于三种模板。包内 `provenance.json` 精确记录该源路径和 SHA-256。`*_hal_timebase_*_template.c` 属于可选示例，不计入 HAL 库默认编译源。

F005 镜像没有 GCC 启动文件与链接脚本。生成器按 Puya DFP 中的 ARMASM 中断向量顺序和名称生成 GCC 启动文件，链接脚本以同厂 F002B GCC 段布局为基础，把 Flash/SRAM 边界替换为 F005 DFP 的 32 KiB/3 KiB；这两处是 StudioX 的移植转换，不能视为厂商原版 GCC 文件。

F031/F032/F033/F090/F092 的独立补充包索引在 `artifacts/packs/Puya-Additional-0.1.0/index.json`，重建脚本为 `tools/New-PuyaAdditionalPacks.py`。F031/F032 使用原厂 GCC 启动与链接布局；F033/F090/F092 根据 DFP 向量表转换 GNU 启动文件，并参照同厂 F032 的 GCC 段布局写入各自 DFP 的内存边界。具体固定来源及哈希见各包 `provenance.json`，移植说明见 `examples/packs/puya.py32-additional/README.md`。

F410/F420 的独立包索引在 `artifacts/packs/Puya-F410-F420-0.1.0/index.json`，重建脚本为 `tools/New-Py32F410F420Packs.py`。两系列的 OpenPuya 固定提交镜像仅作固件源码来源，属于非官方镜像；型号和容量另按普冉现行数据手册及产品页核对。原镜像无 GNU 启动和链接文件，生成器按原厂向量表转换启动文件，并按各型号内存容量生成链接布局。F410 的 CMSIS/LL 模板采用同版原厂 LL 示例的纯寄存器 `system.c`，避免 HAL 宏依赖；F420 固件库没有 LL 源码，仅提供 CMSIS/HAL 模板。来源哈希与许可证见各包 `provenance.json`，详情见 `examples/packs/puya.py32f410-f420/README.md`。

## 验证范围

`StudioX.VendorPackValidation` 对每个包和容量型号检查工程生成、器件定义、链接内存范围与 ELF 向量，并在 F0 系列逐型号真实构建 CMSIS/HAL/LL 三种模板。首批 22 个容量型号完成 66 次编译；补充 5 个容量型号完成 15 次编译，均无失败。构建只证明工程配置和最小固件可编译；无样品时未验证实板时钟、外设功能、烧录及调试。由于尚无能在下载前严格核对 Puya 硅片身份及容量的 OpenOCD 配置，本批包没有声明下载/调试目标。请勿将其他厂牌的通用 Cortex-M 烧录脚本用于这些包。

随 OpenPuya 镜像提交 `982757404a416dd1e0fde921750d61167aed09ee` 附带的旧 DFP 1.0.2 把 F403xB 都标为 64 KiB SRAM；现行原厂资料明确 K1BU6 仅为 **32 KiB**，本包按原厂完整料号写 32 KiB，并为各型号生成独立链接内存边界。镜像来源、DFP 哈希、选用的 GNU 启动文件与各 SDK 文件哈希见包内 `provenance.json`。当前官网公布的 Firmware Library 1.4.8、Keil DFP 1.0.12 并未用于构建此包；2026 年新列 `-C` 修订料号因单独参考手册与旧镜像兼容性未确认，暂未收录。

包提供 CMSIS、Puya HAL、Puya LL 模板。离线验收报告在 `artifacts/validation/Puya-F403-0.1.0-r3/result.txt`：11 个完整料号创建了 19 个工程，按容量/头文件/模板组合做了 12 次真实 ARM GNU 编译，全部通过，并检查 ELF 向量和链接范围。未连接实板，包未开放下载或调试。

## PY32F410 / PY32F420 完整料号

F410 的[官方数据手册 V1.3](https://www.puyasemi.com/download.html)列出七款常规料号；其中 `PY32F410G18U7` 的 SRAM 容量与[官网产品页](https://www.puyasemi.com/iotwulianwang/3794.html)冲突，暂不收录。其余六款均为 128 KiB Flash / 16 KiB SRAM：`PY32F410R1BT7`、`PY32F410C1BT7`、`PY32F410C2BU7`、`PY32F410K1BT7`、`PY32F410K1BU7`、`PY32F410G1BU7`。[F420R1CT7](https://www.puyasemi.com/gongye/3857.html) 与 [F420C2CT7](https://www.puyasemi.com/py32f420xilie/3858.html) 的原厂产品页均列 256 KiB Flash / 48 KiB SRAM。

两包的离线验收报告在 `artifacts/validation/Puya-F410-F420-0.1.0/recheck1/result.txt`：8 个完整料号、11 次工程创建、5 次代表性真实 ARM GNU 编译，均通过内存与 ELF 检查。无样片，本包不声明 OpenOCD，IDE 未开放下载或调试。
