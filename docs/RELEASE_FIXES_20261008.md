# MCU StudioX 0.2.6 LTS 修复版（2026-10-08）

发行标签：`v0.2.6LTS-fixes-20261008-r2`。产品显示版本保持 `0.2.6LTS`，Windows 文件版本保持 `0.2.6.11`；安装器支持同版本修复。

## 修复内容

- 普通 CMake 器件工程与 Keil 移植工程使用实际编译数据库。用户添加的头文件目录、宏和逐文件语言标准同步进入实时诊断、补全和跳转；修复编译正常但 `BH1750.h` 找不到、大量未定义红线的问题。
- 原工程在 IDE 关闭后被删除，再次启动进入开始页并保持工程未打开。恢复草稿独立归档，避免重复跳转故障页。
- 条件编译未启用分支按当前文件的实际宏配置变暗，支持嵌套条件、头文件宏、深浅主题与分屏，编辑后清除过期着色。
- Keil 工程移植插件支持应用级会话，无需先打开无关工程；文件和目录通过浏览窗口选择，预览与原工程保护保留。
- 外部 MCP 会话绑定工程后自动授权操作，保留路径、文档哈希、器件及会话检查，减少重复确认弹窗。
- 修正插件未提供说明时误显示“清单读取失败”的提示，并补充内置 CSV 示例插件的用途说明。
- 预装 STM32 包更新为 23 个子系列的 0.1.3 完整库矩阵；244 个器件均提供 HAL、SPL、LL 及对应 FreeRTOS 模板。GitHub 器件包下载和自动更新校验库矩阵。

## 下载与安装

提供 Windows x64 完整版和轻量版，二者使用同一源码提交和 71 个器件包：

- `MCU-StudioX-0.2.6LTS-win-x64-Setup.exe`：完整版，预装受管理的开发工具。
- `MCU-StudioX-0.2.6LTS-win-x64-Light-Setup.exe`：轻量版，按工程需要选装工具。
- `studiox.keil-importer-0.1.5.studioxplugin`：可选 Keil 移植插件，通过插件管理导入、信任并启用。

安装前关闭 IDE，在已有位置执行安装器即可修复或升级；保留用户配置、草稿、个人工程和已经安装的工具版本。旧发布及其标签保留。本次不新增硬件连接或烧录验收。

正式发布附带源码归档、验证记录与 `SHA256SUMS.txt`。安装器沿用现有未签名分发方式。
