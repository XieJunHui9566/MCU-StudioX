# 后续开发边界

产品方向是面向多系列器件的完整重型 IDE：开箱即用、新手友好、功能多、插件可扩展，开发环境组件由 IDE 独立管理。通用编辑体验、可靠工程操作和插件契约优先服务所有系列。

本轮已接入工程搜索替换、C/C++ 实时错误、引用与语义重命名、标签和未保存内容恢复，大工程性能优化及七步交互式[第一个工程引导](FIRST_PROJECT_GUIDE.md)也已接入。后续继续完善增量索引与编辑一致性、插件能力契约、升级回滚及故障反馈。具体边界见 [编辑工作区](EDITOR_WORKSPACE.md)。

脚手架之后已接入内置开发环境组件，并对隔离工程进行实际编译。以下列出当前进展和后续工作；编译通过不代表硬件验证完成。

1. 固定格式和服务契约：为包、工具目录、工程生成、取消/超时、设备队列和插件协议补充边界测试。
2. 发行开发环境组件：已整理 Arm GNU、xPack RISC-V、AGM AgRV 三套工具及对应 OpenOCD/GDB、CMake/Ninja，接入完整性校验、启动检查和自包含发行目录；后续补充正式发行的来源审计、对应源码材料、安装器与更新回滚。
3. AG32 器件包：按当前厂商手册提供 VF303/VF407/VH303/VH407 四个子系列、七款精确型号与对应封装的图形化引脚配置，生成入口是 `tools/New-Ag32Packs.py`。AG32VF303CCT6 已完成授权的实板下载与调试验收，其它型号的离线工程和映射支持不扩大为硬件验收；后续逐型号核对身份、板级连线和硬件行为。
4. 编辑工作区：已有多文件标签、独立撤销、工程搜索替换、clangd 补全/导航/引用/重命名/实时诊断和编辑现场持久化；大工程已接入异步文件树、快开扫描复用、IDF 后台统计与性能测量。后续完善增量文件发现、编译数据库覆盖范围与恢复冲突处理体验；实时分析与实际构建结果分别标注来源。
5. 连接服务：真实串口和 TCP 适配器；在同一会话上接串口助手、解析器、绘图、记录回放。串口分包和协议帧边界不应由绘图 UI 决定。
6. 下载与调试：已接入包定义的 OpenOCD 单次下载（器件检查、映像范围写入、校验、复位和日志）；F1/F4 已按 23 个子系列分包，覆盖 244 个基础型号及四模板，提供 ST-Link/DAP/J-Link 选择并完成代表性编译。后续进行三种烧录器的实板测试，以及 GDB 会话、目标状态机、断点、寄存器/SVD。详见 STM32_SERIES.md。
7. 实用工具：协议主从模拟、时序采集和波形查看、多路数值图；区分宿主时间与设备/采集卡时钟。
8. 用户扩展：已有持续插件宿主、显式信任、安装/更新和 API 3 设置、事件、语言、调试快照能力；[调试扩展完整使用链](DEBUG_PLUGIN_WORKFLOW.md)补充了自动刷新、过期数据撤销、插件发现及直接入口。后续补充作者签名和来源验证、插件分发及更多能力契约；主题编辑、可持久化停靠布局和外观资源。
9. 产品化：安装器、升级回滚、崩溃恢复、日志反馈、性能和长时间采集测试。

调试连接向导、故障分析工作台、构建历史比较、基础/完整发行配置及工具/插件/源码组件分发已接入，详见 [产品工作流](PRODUCT_WORKFLOWS.md)。下一步是公开目录治理、产品签名、代表性真实故障样本与更多框架的组件构建验证；不能把离线验收扩展为实板验收。

以后验证使用独立测试临时目录；不自动下载厂商 SDK，不自动烧录已连接的硬件。
