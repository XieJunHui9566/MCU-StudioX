# CH32V307 器件包与 FreeRTOS 模板

当前独立包 `wch.ch32v307/0.1.3` 收录 CH32V307VCT6、CH32V307RCT6、CH32V307WCU6，保留原有 `spl`「标准库 · 精简 main」，新增 `spl-freertos`「标准库 + FreeRTOS」。默认外部 8 MHz 晶振运行到 144 MHz，256 KiB Flash / 64 KiB SRAM；开发环境组件仍为 `wch.riscv/1.0.0`。0.1.3 同步更新包内 README 的模板与调试状态说明，固件源码与 0.1.2 相同。

FreeRTOS 使用本机 MounRiver Studio 2 随附的 WCH 官方 V10.4.6 内核及 QingKe/PFIC 移植。ZIP SHA-256 固定为 `f4711a1990a223578b18230e37d6e1e31f2c5deb8b527cc79e11610c0c1bb56a`。来源见 [WCH 官方 SDK](https://github.com/openwch/ch32v307/tree/main/EVT/EXAM/FreeRTOS)，包内 `vendor/provenance.json` 与源文件保留来源及许可声明。普通模板和 RTOS 模板分别使用对应官方启动文件；不合并两套中断上下文配置。

在新建工程的模板下拉框选择「标准库 + FreeRTOS」。`src/main.c` 提供 200 ms、500 ms 两个任务的可观察计数器，不使用板级 GPIO 或串口。`include/FreeRTOSConfig.h` 可编辑，默认 `heap_4`、12 KiB 堆、128 字任务最小栈和独立 ISR 栈，软件定时器默认关闭；创建任务或调度器启动失败时保留 `studiox_rtos_start_error`。

CH32V307VCT6 的新 RTOS 模板已通过真实 WCH GCC 12 离线编译，Flash 占用 5628 字节、RAM 占用 15396 字节。在由此模板生成的隔离验收工程中，添加观察配置及五种同步对象后，7984 字节试验固件已在 VCT6 / WCH-LinkE 上完成授权下载、完整映像校验和 FreeRTOS V10.4.6 任务、栈水位、堆及对象状态的实板 MCP 验收，见 2026-09-26 RTOS 记录（本地记录）。RCT6/WCU6 使用相同内核、容量及固件支持文件，包中分别保留各自芯片 ID 检查与下载配置，尚无 RTOS 实板验收；旧裸机调试和中断证据见 验证记录（本地记录）、[中断约定](CH32V307_INTERRUPTS.md)。

0.1.3 的 VCT6 `spl` 裸机模板也通过回归编译（Flash 1548 字节、RAM 2080 字节），确认普通启动文件和模板 SDK 裁剪完整；原始日志位于 `.artifacts/ch-rtos-final`。
