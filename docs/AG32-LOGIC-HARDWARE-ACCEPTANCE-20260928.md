# AG32 MCU + FPGA 内部回环验收（2026-09-28）

用户已接入实板并授权使用。当前 AG32VF303CCT6 通过 CMSIS-DAP HID、1 MHz SWD 连接，器件 ID 为 `0x40200001`，物理 Flash 为 256 KiB。现有逻辑配置要求在 `0x80027000` 存放未压缩镜像，本次保持该布局。

## 结果

| 检查 | 实际结果 |
|---|---|
| 原程序备份 | 完整读取 262,144 字节，包含应用与 FPGA 逻辑区 |
| MCU 镜像 | 1,716 字节，写入 `0x80000000`，独立回读 SHA-256 一致 |
| FPGA 镜像 | 99,944 字节，写入 `0x80027000`，独立回读 SHA-256 一致 |
| 内部逻辑自检 | 单次启动已观察到 55,933 次检查、0 次错误 |
| 复位启动 | 复位后重新累计 2,176 次检查、0 次错误 |
| 暂停与继续 | 独立只读会话中，继续运行 2.5 秒，检查数从 43,527 增至 46,257，错误数仍为 0 |
| IDE 电路图 | 同一份 `logic_unit.v` 经内置 Yosys 生成 7 个元件、8 个端口，源文件哈希一致 |

MCU 通过内部 GPIO4 的八根信号连接 FPGA：五根输出提供 `a`、`b`、`sel`、测试时钟和复位；三根输入读取组合结果、寄存器结果及两位计数器的奇偶校验。每轮覆盖八组输入、上升沿更新、下降沿保持及异步复位，共 25 次检查。没有把这些测试信号分配到外部封装脚。

测试结果保留在 RAM 中的 `logic_test`，本次 ELF 地址为 `0x2000010c`。后续重新编译应从 ELF 符号表读取地址，不能沿用固定地址。最后已退出 OpenOCD，保留测试程序运行；原固件未恢复。

## 工具与边界

- MCU 由 StudioX CLI、锁定的 `agm.agrv/1.0.0` 开发环境组件编译。
- 硬件位流由本机已有的 AGM Supra 2026.03 原生 mapper 和布局布线工具生成，本次未调用 Quartus。厂商生成的批量下载文件采用另一套默认布局，未使用；实际下载严格使用已读出的板上布局。
- IDE 中的 RTL 图由内置 Yosys 生成。这次实测不意味着 IDE 已实现自定义逻辑的一键综合、布局布线和联合下载；该功能仍须独立接入应用服务。
- 时序报告仍有 7.7% 连接未覆盖。测试时钟由 MCU 软件产生并留出稳定时间；跨时钟关系由回环断言验证。本次证明所测功能正确，不构成完整时序签核、最高频率或外部引脚验收。

## 下载观察

首次临时脚本仅执行 `halt` 后写 Flash，厂商驱动报告 `Flash write target timed out after 321 ms`。采用 IDE 已有的 `reset halt` 下载顺序后，两段镜像写入并校验成功。此结果不能把所有偶发下载失败都归因于同一原因，也没有加入失败后自动重写 Flash 的行为。

工具最初读选项区就报告 `option byte complement error`，同时报告读保护关闭、逻辑地址与补码匹配。该现象作为原始诊断保留；本次未修复或写入选项字节，前后逻辑配置两字保持 `0x80027000 / 0x7ffd8fff`。
