# STC 下载配置页

2026-11-01 用户将范围从 IAP15L2K61S2 扩大到所有 STC 8 位和 32 位工程。统一入口是下载按钮旁的设置按钮，打开独立工作台文档页，不增加下载确认弹窗。

## 页面与保存

- “器件与模板”只显示编译优化选项；调试信息、Mon51 资源预留、Flash 上限移到下载配置页的“调试与构建配套”。它们仍保存在 `.studiox/build.json`，通过原构建服务验证，保存后重新编译。
- MX251 的内存模型也移到配套区域，仍由 `mx251.json` 管理。当前编译器没有优化等级命令行开关，界面如实说明内置策略，不生成虚构参数。
- 串口、波特率、时钟与硬件选择保存在 `.studiox/stc-isp.json`；32 位 USB 的已支持设置继续使用自己的专用设置及协议服务。
- 打开设置只初始化尚未加载的数据。已有编译、串口、频率和硬件草稿不会因导航被重载。切换到器件与模板同样保留已加载草稿；调试发现未保存输入时定位到对应区域并停止启动。
- 长表单使用固定页头、准确型号、分组定位与保存动作。主题、强调色、字体、滚动条、输入框复用公共资源。

## 目前可写范围

串口使用随 IDE 管理的 stcgal 1.10 编码器；StudioX 门禁在同次实机识别后、校准及擦除前核对选项类并在隔离副本上验证每个值。未指定字段不修改，从本次实机 MSR 保留，而不是使用固定默认字节。硬件修改开关关闭时只保存草稿，不向下载命令发送覆盖项。

| 选项类 | 页面配置 |
| --- | --- |
| STC89 / STC90 | 6T、ALE、XRAM、振荡器增益、上电看门狗、EEPROM 擦除、下载引脚条件 |
| STC12A | 低压档位、看门狗启动/空闲停止/分频、EEPROM 擦除、下载引脚条件 |
| STC10/11/12 | 复位脚、低压复位、振荡器稳定周期、复位延时、增益、看门狗、EEPROM、下载引脚条件 |
| 小容量 STC15A | 复位脚、低压复位及档位、低压 EEPROM 保护、看门狗、EEPROM、下载引脚条件 |
| 完整 STC15 / IAP15 | 在相应基础上提供复位延时、P3.3 初始输出、UART2 透传/引脚模式；CPU 核心电压还要求实机状态含此字段 |
| STC8 | 相应复位、看门狗、低压、EEPROM 与引脚条件，以及 P2.0 初始输出、UART1 重映射、UART2、增强 PWM 输出 |
| STC8H8K64U / 原生 USB / ISP 7.4.12U | 复位脚、振荡器增益、上电复位延时、低压复位及档位、看门狗启动/空闲停止/分频、下次 EEPROM 擦除与下载引脚条件，共 10 项；使用独立 USB 编码器 |

时钟沿用各协议的能力声明。小容量 STC15A / STC8 不发送不存在的 `clock_source` 选项；STC12A / 完整 STC12 / STC15 仅在识别到该字段时切换来源。低压档位保留协议编号，不能把 STC8 或 5 V 器件的电压表复制到 3 V IAP15L。

普通下载快照包含完整硬件设置，准备之后更改设置会拒绝旧快照。Mon51 自动制作使用独立受校验镜像和保留硬件的原流程，不应用普通程序的硬件覆盖。只改界面、保存设置和离线验证不打开串口。

## 尚未补齐的功能

这是当前限制，不代表全系列高级选项已经完成。

- STC8H8K64U 原生 USB 时钟仍只支持保留或内部 RC 24 MHz。上表 10 项硬件设置已接入；其它串口字段保留草稿但不允许应用到 USB。必须将其改为“保留”或切回串口。当前实机分区不是 65024 B 代码 / 512 B EEPROM 时在擦除前拒绝，不擅自重分区。
- MX251 / AI8051U 32 位专用后端保留已核对的 32 位模式与 1–48 MHz IRC。其它硬件位尚未完成独立映射与写入核对，未开放修改；STC32G 等目标不能因此获得新硬件资格。
- 快速下载开关、RS485 等待、程序尾追加调节参数、此次 EEPROM 全填 FF、Flash 空白区填充及 EEPROM 分区尚无完整接入。界面明确说明，不提供空实现的开关。
- 新 STC12H / STC15H 不能套用旧协议；未支持器件不会因新增页面而开放下载。
- 各项编码及流程已做离线验证；本轮未烧录、校准或修改实际芯片硬件配置，不能宣称硬件写入验收。

## 实现依据及验证入口

本机版本锁定的 `stcgal/options.py`、`protocols.py`、`frontend.py` 是实际编码依据；上游源代码见 [选项编码器](https://github.com/grigorig/stcgal/blob/master/stcgal/options.py) 与 [协议实现](https://github.com/grigorig/stcgal/blob/master/stcgal/protocols.py)。前期全系列审计、官方下载样本与只读实机记录见 `STC-ISP.md`、`STC8H-NATIVE-USB.md` 及 `.artifacts/stc-options-tests-20261101/`。沿用修复后的 UART2 / 复位位编码，冻结包计划不得变化。

- `StudioX.StcIspValidation --settings-offline <python> <新输出目录>`：编译后 DTO 持久化、跨系列字段和值、真实编码器交叉检查、未知字段和擦除前门禁。
- `StudioX.StcIspValidation --options-offline <python> <新输出目录>`：全系列配置安全回归及冻结选项包。
- `StudioX.StcIspValidation --usb <runtime> <pack> <新输出目录>`：既有官方 HID 回放、28 个官方 PE 编码器离线对照、7168 个按位保留组合、分区与非法设置擦除前拒绝，以及真实 CMake / Ninja / SDCC 构建。新增选项尚未进行逐项实板验收。
- 普通 ISP 离线验收：实际 SDCC 构建、配置快照变更拒绝、型号及固件散列门禁；不连接硬件。
- `--preview-stc-download-settings <新输出目录>`：6 个系列/目标、深浅主题、自定义强调色及 18 px 字体，保存实际 WPF 渲染。
- `--preview-mon51-settings`、`--preview-stc-usb` 及 Mon51 `--launch-offline`：导航、草稿、两次上电提示和专用监控制作回归。
