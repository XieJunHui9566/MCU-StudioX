# CH32V203 软件适配（2026-09-23）

## 2026-09-26：FreeRTOS 模板

当前包为 `wch.ch32v203/0.1.1`。保留原有 `spl` 裸机模板，新增 `spl-freertos`「标准库 + FreeRTOS」。新模板使用本机 MounRiver Studio 2 随附的官方 CH32V203 FreeRTOS 移植、对应 D6/D8 启动文件、PFIC 软件中断和 SysTick；不能把 NoneOS 的中断压栈配置套用于 RTOS。

FreeRTOS 模板覆盖下方型号表中 V20x 分支的 10 个型号。**CH32V203CCT6 使用 V205 内核及独立库，尚未核实对应 RTOS 移植，本次继续只提供 `spl`。** 本机官方 ZIP 的 SHA-256 为 `8a0b91a05ce879c63e2feec2cedfbdac577bef50f3e9e1b73b8f7e6d5efcb4c9`，参考 [WCH 官方 SDK](https://github.com/openwch/ch32v20x/tree/main/EVT/EXAM/FreeRTOS)。内核及移植代码保留原始许可声明，包内 `vendor/provenance.json` 记录来源；不新增下载整套 SDK。

模板在 `src/main.c` 创建 200 ms、500 ms 两个独立任务，只更新可调试计数器，不初始化未知板卡的 LED/串口。`include/FreeRTOSConfig.h` 属于可编辑的工程配置，采用 `heap_4`、128 字任务最小栈和独立 ISR 栈，软件定时器默认关闭。10 KiB SRAM 型号默认堆为 4096 字节，其他型号为 8192 字节，可按应用需要调整。创建任务或调度器启动失败时保留 `studiox_rtos_start_error`。

新 RTOS 模板仅做离线编译验证，不把过去 C8T6 裸机调试验收扩展为 RTOS 实板验收。本次 C6T6（D6，32 KiB Flash / 10 KiB RAM）的真实 WCH GCC 12 编译通过，Flash 占用 5132 字节、RAM 占用 7204 字节；RBT6（D8，160/32 KiB）也通过，Flash 5492 字节、RAM 11300 字节。包生成脚本仍按每个器件容量、启动文件及 ISA 生成工程。

## 构建、时钟和中断

- HSI 默认避免依赖未知的板载晶振。要求精确 USB 等外设时钟时，按实际板卡调整 `device/system/`；编译优化和调试信息继续使用工程的编译参数设置。
- 普通 V203 使用 `rv32imac_xw / ilp32`；CCT6 使用 `rv32imc_zba_zbb_zbc_zbs_xw / ilp32`，与 WCH GCC 12 的对应 multilib 匹配。GCC 12 的汇编器不接受没有版本的 `rv32imcb_xw` 简写。
- V20x 保留官方启动的 CSR `0x804 = 0x3`，`System_Init()` 使用官方 `NVIC_PriorityGroup_1`。CCT6 保留自己的启动配置（包括 CSR `0x804 = 0x7`），不调用 V20x 的优先级分组 API。
- 保留官方 fast 中断属性。自定义 C 入口需声明 `__attribute__((interrupt("WCH-Interrupt-fast")))`，C++ 还需 `extern "C"`；普通函数不能直接代替中断入口。V307 的三级硬件压栈测试结论不能直接用于 V203。

## 下载与调试

- WCH-Link / WCH-LinkE，RISC-V / SDI；默认 4000 kHz，可选 400 / 4000 / 6000 kHz，单台探针，序列号留空。
- 型号按芯片 ID 核对，只忽略修订位。读保护时拒绝操作，不自动解锁。固定容量型号不套用 V307 的内存划分判断；RBT6 检查选项字节互补值以及 160 / 32 KiB 划分，拒绝 128 / 64、144 / 48 布局。
- 下载使用明确的 page erase，写入之前先校验目标；校验固件后以 `reset halt; resume` 运行。
- 调试附加核对板上固件，不隐式下载；禁用 Flash 编程，校验时工作区大小为 0，避免覆盖运行中的 SRAM。分离时确认目标恢复运行。
- V203 不请求厂商 GDB 泛列的 FPU 寄存器；保留整数寄存器、`pc` 和基础机器 CSR，`fp` 仍作为整数帧指针保留。V307 继续显示实际具备的 FPU 寄存器。
