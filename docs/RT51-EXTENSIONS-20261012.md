# RT51 静态内核扩展记录

2026-10-12。当前开发源码仍为 RT51 0.1.0，器件包候选为 stc.stc8 / 0.1.5；
IDE 产品版本保持 0.2.6.13。最初的扩展开发阶段不连接/下载硬件、不替换安装版、不发布 GitHub。
此前实板记录对应 0.1.4 归档及旧固件，不能作为本轮新增功能的实板证据。

## 实现

- `rt51_delay_until`：XRAM 周期锚点，16 位安全差值，周期 1..32767 tick；逾期返回
  TIMEOUT，保留推进后的锚点，调用者选择补处理或重置；取消后返回 ABORTED。
- `rt51_task_suspend/resume`：取消未完成等待，防止队列迟到发送、许可丢失及遗留
  锁继承；拒绝挂起持锁者和正在派发回调的任务。自挂起后从原调用处恢复。
- `rt51_timers.c`：启动前注册静态对象；有界 tick 累计到期；任务调用 dispatch 派发，
  每对象每次最多一个回调。支持单次/周期、启停、回调内重启/取消、积压及饱和溢出诊断。
  不在 ISR 执行回调，不额外创建服务任务；阻塞/任务控制 API 拒绝回调上下文。
- 任务/内核/定时器原子快照：状态、有效优先级、等待、观测栈水位、tick 采样与切换数。
  采样统计不等于精确 CPU 用时，也不构成硬实时延迟上限。
- `RT51_MAX_TIMERS=0` / `RT51_ENABLE_STATS=0` 可裁剪模块/统计字段；全工程统一配置。
  用户提供的定时器初始化及 tick_ack 接口保持不变。

## 离线验证

工具为工程管理的 SDCC 4.5.0 #15242 与 s51/uCsim 标准 C52 指令仿真。
原始日志与固件保存在 `.artifacts/rt51-extension-20261012/`。

- 默认配置 31 项执行检查全部通过，包含原 17 项回归和 14 项扩展；故障路径核对错误码。
- 裁剪配置 25 项全部通过，关闭定时器/统计后仍支持周期延时、任务控制和快照。
- Size 优化 16 项及 Speed 优化 13 项针对上下文/算术、回绕、取消、定时器和快照的检查通过。
- 各执行检查逐字节检查 0400..06FF 完整 768 字节哨兵，核对 P3 不变；内核水位小于 80 B。
- 实际包导入/工程生成/普通与 Mon51 的 SDCC 构建共 21 项检查通过。
- `tools/Build.ps1` Release 隔离构建通过，0 警告、0 错误，不复制全量工具到验证目录。

完整配置模板示例链接报告：9647 B CODE、532 B XRAM；硬件任务栈 80..FF 保持 128 B，
内核工作栈 30..7F 保持 80 B，每任务保存上限 96 B。相较 0.1.4 示例新增 3191 B CODE、
45 B XRAM，包含默认统计/指针表、一个软件定时器及应用计数。用户 XRAM 仍限 0001..03FF，
CODE 仍限 0000..DBFC，不扩展进入监控保留区。
关闭定时器和统计后，同一示例实际链接为 7729 B CODE / 493 B XRAM。

## 剩余边界

用户随后授权下载，新验收固件已在同一块 IAP15F2K61S2 板完成 60 秒运行及断电后
30 秒运行检查，见 [扩展实板记录](RT51-EXTENSIONS-HARDWARE-20261012.md)。
0.1.5 归档没有覆盖重写，其中附带文档仍反映归档时的离线状态。
尚未做长时间压力测试或最坏中断延迟测量。8051 的栈复制与关中断
窗口仍限制响应速度；tick 周期正确不等于切换耗时已经量化。回调执行延迟还受服务任务
优先级和派发间隔影响。状态查询接口已提供，尚无 RT51 专用任务窗口。
当前不支持动态任务生命周期、运行中修改优先级、流/消息缓冲、低功耗或 Keil C51 端口。
