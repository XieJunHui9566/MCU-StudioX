# 外设寄存器窗口

从「调试 → 外设寄存器（SVD）」进入。先选择厂商 `.svd`，依据厂商器件包核对它对应当前工程的器件型号，再确认绑定。不能仅凭文件名或系列名称判断型号。绑定及内容副本存入独立用户数据目录，不向工程写入本机绝对路径。

支持外设/寄存器/地址/说明搜索、访问权限、复位值、位域及枚举值。列表虚拟化，解析在后台执行。复位值是参考值，只有显式读取后才显示本次目标数值。目标运行、单步、复位、结束或换工程后立即清除旧值。

读写共用当前调试会话的命令锁和 GDB，不另开探针连接。实机必须暂停，固件必须先通过 ELF 校验。SVD 绑定器件和本轮配置器件必须一致，模拟会话不能读写 MMIO。

带 readAction 的寄存器或位域需要单独确认一次读取，不自动轮询。未声明副作用不保证厂商描述完整，操作时还需核对手册。写入只接受预览并确认的完整值，不执行隐式读改写或读回。只读、未知访问权限、一次性写入、带写约束或有只读位域的寄存器禁用直接写入。W1C 等语义显示在预览中。状态变化使旧的写入预览失效。

支持 8/16/32/64 位、32 位地址、外设/寄存器/位域继承、嵌套 cluster 和 dim 数组。非 8 位地址单元不支持。单文件限 32 MiB，最多 20,000 个展开寄存器；禁止 DTD、外部实体与网络 XML 解析。损坏或不支持的定义保留诊断，不猜测地址。

已解析本机缓存 Keil.STM32F4xx_DFP 3.1.1 的 ST STM32F407 SVD。PDSC 将 STM32F407 子系列映射到 CMSIS/SVD/STM32F407.svd，并声明 STM32F407ZG 的 Flash 为 1 MiB。SVD SHA-256：58787085FFDBFF63572371D6A4AD1E9502B2E647E4DB08C6188A18A8F7119E2A；ST 文件许可证 Apache-2.0。导入校验不等于全部外设实板验收。

规范依据：[Arm CMSIS-SVD 寄存器定义](https://arm-software.github.io/CMSIS_5/SVD/html/elem_registers.html)。
