# MCU StudioX 0.2.3 预览版

本版新增公开 GitHub 器件包仓库同步。IDE 正常启动后在后台检查、增量下载并自动导入最新版本；「文件 → 从 GitHub 同步器件包」可手动重试。同步进度、取消和失败原因显示在「器件与模板」页及构建日志中。离线时已有包仍可使用。

下载固定在一次 GitHub 提交，校验目录、压缩文件 SHA-256、包内身份和 StudioX 格式 1 文件索引；旧版本保留且可在新建工程时选择。公开仓库目前只包含经过再分发检查的部分器件包。详见[在线器件包同步](REMOTE_PACKS.md)。

此版的桌面编译、独立同步验证和窗口冒烟测试已通过。在线仓库可达性依赖用户网络；各器件型号仍须按其各自记录判断编译和实板验证状态。
