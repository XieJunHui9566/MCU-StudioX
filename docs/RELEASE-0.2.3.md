# MCU StudioX 0.2.3 预览版

此版本发布 Windows x64 IDE 的最新源码。已有的 0.2.2 网盘安装包早于这些源码改动；本次 GitHub Release 不附带新的安装包。

## 更新

- AI 助手增加清晰的对话气泡、项目历史与新对话、运行中追加提示、思考强度选择、实时活动与授权卡，以及 API 实际返回的上下文和缓存用量。Agent 修改文件后，编辑区会刷新磁盘内容，并保留用户尚未保存的缓冲区。
- 内置 Agent 和外部 `StudioX.Cli mcp` 共用工程读写、编译、Git、烧录、调试、串口、绘图、器件资料、网络搜索和外部示例读取工具。外部目录按会话授权；写入、硬件连接及下载等操作仍需逐次确认。Agent 不设固定工具调用次数上限。
- 新增四项 MCU Skill，覆盖构建修复、器件资料核验、调试串口和代码风格；按需加载技能正文。`pdf_list`、`pdf_inspect`、`pdf_page` 提供数据手册文字检索及原理图页面/局部图像；视觉结果只进入紧接的一次支持图像的模型请求，不写入对话历史。
- 公开器件包仓库采用**手动检查、手动同步下载**。检查更新不下载包；同步时固定 GitHub 提交并核对大小、SHA-256、包身份和内部索引。旧版及非公开器件包保留，离线使用不受影响。
- 保留此前的编辑、构建下载、调试、串口终端与绘图、Git 图谱等能力。准确型号的编译通过和实板验收仍须分别核对，不以界面截图代替硬件测试。

详见 [AI 与 MCP](AI_AGENT.md)、[外部 MCP 客户端](AI_MCP_EXTERNAL.md)和[在线器件包同步](REMOTE_PACKS.md)。

## 验证与边界

- `tools/Build.ps1` 全量编译通过，零警告。AI 离线检查 28/28、MCP 离线检查 142/142、在线器件包同步离线检查 8/8；另有两项符号链接安全检查因当前 Windows 环境缺少创建权限而跳过。内置和外部 stdio MCP 均验证了 PDF 文字与 PNG 图像块。
- 使用已有 STM32F407 原理图和数据手册进行了只读文字搜索、整页与局部渲染核对。编译与离线检查不代表每个器件包或 AI 工具已经完成实板验收。
- PDF 页面视觉读取限定于当前工程或已获批的外部目录。公开网络 PDF 的文字可尝试由 `web_fetch` 提取；该服务不保证所有 PDF 均可提取，也不提供原理图页面图像。
- 本仓库不包含编译器、厂商 SDK、器件包二进制、硬件备份或用户凭据；厂商 Logo 未随公开源码分发。
