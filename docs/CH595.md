# CH595 器件包

## RTOS 模板的核实范围

2026-09-26 核对本机官方 MounRiver CH595 SDK 仅有 NoneOS 模板，目前未找到可核实的 CH595 专用官方 FreeRTOS/RT-Thread 移植。因此 `wch.ch595/0.1.0` 暂时保留原有裸机模板，不能把 CH592 的不同内核、启动文件和中断移植直接套用到 CH595，也不把 BLE/TMOS 调度器冒称为完整 RTOS。CH32V203（V20x 分支）、CH32V307 和 CH592 的官方 FreeRTOS 模板已单独补入对应器件包。

`wch.ch595/0.1.0` 收录 CH595D、CH595F、CH595X。使用 MounRiver Studio 2 随附的 WCH 官方 NoneOS SDK、启动文件、标准外设库和链接脚本；开发环境组件为 `wch.riscv/1.0.0`（WCH GCC 12、CMake、Ninja、OpenOCD 和 GDB）。三个型号共用固件源码，工程选择按实际芯片丝印与封装进行。

## 创建与编译

在新建工程中选择「沁恒微电子」和实际 CH595D/F/X，再选择「标准库 · 精简 main」。模板从内部 HSI + PLL 运行到 80 MHz，`src/main.c` 中的 `studiox_heartbeat` 可供调试观察，不占用板级 GPIO。修改代码后按 F7 编译。包允许设置工程的编译优化等级。

官方资料列出 256 KiB 物理 Flash 和 32 KiB SRAM；原厂链接脚本及 Flash 库把**用户程序区限定为前 240 KiB**。包的链接和下载范围遵守 240 KiB 边界。目标编译参数为 `rv32imc_zba_zbb_zbc_zbs_xw / ilp32`，与本机官方 GCC 12 工程配置匹配。

## 下载与调试

使用 RISC-V 模式的 WCH-LinkE。根据 [CH595 专用数据手册](https://www.wch.cn/downloads/CH595DS1_PDF.html)，CH595F 的 **PA13（27 脚）接 SWCLK，PA12（28 脚）接 SWDIO**，两端 GND 共地；开发板需可靠供电。旧版通用 CH59x 接线表所述 PB15/PB14 不适用于 CH595。CH595D/X 的实际封装引脚号请按各自引脚表核对。

两线调试接口需要先在官方 ISP 工具中开启。CH595F/D 默认通过 PB15 低电平上电进入 USB Boot，CH595X 默认使用 PB22；USB ISP 使用 PB10/PB11。开启后退出 Boot 模式并重新上电，再由 IDE 通过 WCH-Link 连接。IDE 下载先检查家族 ID `0x97`、读保护和映像边界，然后页擦写、校验、复位运行；读保护时拒绝自动解锁。调试只附加并核对板上固件，不隐式下载。

官方资料没有说明单独开启两线调试是否影响已有程序。解除代码读保护会擦除用户区，因此应先检查保护状态；IDE 不会自动执行解除保护或选项字节修改。包内的只读 ID 能识别 CH595 家族，不能证明 D/F/X 的具体封装。当前 NoneOS SDK 不含已核实的 BLE 协议栈，本包提供普通 C/外设开发模板。

当前已完成 CH595D/F/X 的离线建工程、编译和调试配置验证，尚未使用 CH595 实板验证下载和调试。CH592F 与 CH595F 的两线调试引脚不同，连接和固件不可混用。

资料：[CH595 产品页](https://www.wch.cn/products/CH595.html)、[官方 EVT](https://www.wch.cn/downloads/CH595EVT_ZIP.html)、[WCH-Link 使用说明](https://www.wch.cn/uploads/file/20250124/1737704462135866.pdf)。
