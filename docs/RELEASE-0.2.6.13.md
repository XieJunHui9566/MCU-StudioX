# MCU StudioX 0.2.6.13

Windows x64 完整版和轻量版安装包，产品、程序集与 Windows 文件版本统一为 0.2.6.13。可覆盖升级 0.2.6.12 和 0.2.6LTS，沿用原安装位置并保留已有开发环境组件、用户设置和工程。两者使用相同 IDE 代码，随包提供 71 个器件包、Git、语言服务与插件宿主；完整版附带开发环境组件，轻量版按工程需要安装组件。

## STC 下载与 Mon51 调试

- Mon51 V2.5 监控固件放入 `stc.stc8 / 0.1.2` 器件包。IDE 从包内校验并读取镜像，通过内置 ISP 制作仿真芯片，无需导入或启动外部 STC-ISP。
- 调试窗口提供「设置为仿真芯片」和完成后的断电上电提示。激活监控后，开始调试会构建最新用户程序，通过 Mon51 写入用户区、完整回读校验并加载符号，无需每次重新上电。
- 普通「下载」继续走正常 ISP 流程；普通下载会覆盖代码区及可能存在的仿真监控，再次调试需重新制作仿真芯片。
- 修正冷启动同步顺序与启动入口，保留源码/地址断点、源码与指令单步、寄存器、变量观察、内存与恢复日志功能。源码断点仅在当前固件与符号核对通过后绑定。
- 对 IAP15F2K61S2 / BSL 7.2.5S / 状态 0x70 / 内部 RC 使用从官方成功通信记录核对的首轮 11 点校准请求及 `0x66` 脉冲，接入普通 ISP 下载与监控制作共用入口。其他目标继续使用原协议。

该校准修复已在同一块 IAP15F2K61S2 + CH340C 上完成校准对照及一次普通 ISP 下载，收到完整成功应答；未把这一结果扩大为其他型号、反复下载或修复后监控制作的实板验收。Mon51 支持范围和资源占用见 [调试操作说明](STC-MON51-UI.md)、[包内监控固件](STC-MON51-FIRMWARE.md) 与 [ISP 下载说明](STC-ISP.md)。
