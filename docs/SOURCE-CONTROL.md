# 源码版本管理

从 2026-09-22 的独立 IDE 0.1.0 开发版开始建立 Git 基线。基线包含现有编辑器、构建下载、调试和文字串口功能；之后按功能提交，保留可追溯的改动。

- 纳入：`src`、`tools`、示例源码、包生成脚本、文档、许可证与构建配置。
- 排除：`bin`、`obj`、`.build`、`artifacts`、`.artifacts`、缓存、安装包和生成的 `.mcupack`；硬件备份、串口采集与本机工具链留在本地。
- 当前为本地仓库，未配置远程地址、未上传。源码提交与发布版本号分别管理，不因每次提交而自动升级安装包版本。
- 开发前查看 `git status`；完成一个功能后检查差异并提交。构建使用 `tools/Build.ps1`。
- 恢复旧版本时优先使用单独 worktree 或 `git revert`，避免覆盖未提交修改。
- 临时单片机验证工程及其复制的厂商 SDK 放在 `.artifacts/`，不再将完整生成工程纳入 `examples/`。长期维护的器件配方、插件示例和回归检查源码保留；清理前归档硬件备份及验收证据，见 2026-09-22 清理记录。
