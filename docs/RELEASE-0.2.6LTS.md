# MCU StudioX 0.2.6 LTS

本次为 0.2.6 维护分支，产品显示版本为 `0.2.6LTS`，Windows 文件与程序集版本为 `0.2.6.11`。LTS 标识维护方向，当前没有固定支持截止日期。

最终发布标签为 `v0.2.6LTS-final-20261005`；初始准备标签保留原位，正式载荷与最终标签的源码提交绑定。

## 安装与升级

公开提供 Windows x64 轻量安装包 `MCU-StudioX-0.2.6LTS-win-x64-Light-Setup.exe`，包含自包含 IDE、器件包、Git、clangd 和独立插件宿主。开发环境组件按工程需要获取或手动导入，版本分别管理。

安装前关闭 IDE，在原位置覆盖升级。支持从 `0.2.6.10`、`0.2.5.4B` 等旧版升级；同版本可修复，较新的产品版本会阻止降级。已有组件按 ID/版本整个目录保留，不改写工程锁、用户配置、恢复草稿或个人工程，不修改系统 PATH。

旧工具副本的对应源码与再分发材料尚未全部归档，因此本次公开包采用轻量版。已有本机组件继续使用；可公开的独立组件见[开发环境组件库](https://github.com/XieJunHui9566/MCU-StudioX-Toolchains)。

## 维护内容

- 环境恢复与选装流程：故障阶段可观察，恢复保留工程锁和原有组件。
- 实时诊断：未保存头文件、连续编辑、旧诊断、定位范围、取消和语言服务恢复纳入可靠性检查。
- ESP-IDF：支持外设开发辅助、源码与组件依赖预览、确认后应用和撤销；无法可靠分析的 CMake 写法提示手动操作。
- 安全边界：拒绝器件包仓库及目录链接越界，工具输出故障结束自有进程树，插件响应完成前保留请求额度，补齐 Windows 保留设备名检查。
- 源码维护：统一第一方源码风格，拆分公开类型；格式器和 Git 检出保留生成字符串原值，回归入口加入安全、格式和 MCP 契约检查。

## 验证范围

Release 附带与源码提交绑定的回归记录、安装验证记录和 SHA-256 校验和。安装检查覆盖旧版升级、同版本修复、降级拦截、运行中拦截、目录限制、载荷完整性、自包含桌面启动及卸载保留。

本次不新增硬件连接或烧录验收。重点安全边界审查不等于逐行安全认证。安装器未配置产品代码签名证书，SHA-256 用于核对下载完整性。
