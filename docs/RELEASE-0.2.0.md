# MCU StudioX 0.2.0

独立 IDE 的 Windows x64 开发预览版，使用完整离线安装包，可在原目录覆盖升级 0.1.0。

## 本版内容

- 集成 STM32 调试操作：断点、条件/日志/临时断点、单步、调用栈、变量与寄存器。F407 的 ST-Link、DAP-Link 界面联调记录随包提供。
- 新增文字串口终端、ANSI 彩色显示、HEX/UTF-8/GB2312、串口参数与流控设置、Modbus RTU 和用户脚本解析。
- 新增独立串口绘图入口，支持自定义分隔符、多通道实时曲线以及时间和值坐标缩放。
- 内置 Git，新建工程自动初始化仓库，提供工程命令行终端。
- 提供文件内函数/变量列表，以及编辑器、图标、背景、滚轮和工程管理改进。
- 修复 CubeMX 工程因工具路径大小写差异而丢失 ARM 交叉编译配置的问题，自动恢复旧缓存。
- 内置编译、下载和代码提示运行时，附带 23 个 STM32 子系列包及 1 个 AG32 临时包，按厂商分目录。

## 安装与升级

运行 `MCU-StudioX-0.2.0-win-x64-Setup.exe`。已安装 0.1.0 的用户先保存文件并关闭 IDE，再在原目录覆盖升级；工程、已导入器件包和个人设置保留。同版本可覆盖修复，禁止降级。当前通过手动运行完整安装包升级。

器件包位于安装目录或发行目录下的 `device-packs/STMicroelectronics`、`device-packs/AGM`。器件包版本保持各自的 0.1.1，不随 IDE 改为 0.2.0。

## 验证范围

各功能的实机与离线验证范围见本目录相应验收记录。AG32 官方烧录器目标通信异常尚未解决，实机下载/调试未通过本轮验收。安装包未进行代码签名；许可证与第三方再分发材料状态见 `INSTALLER.md`。
