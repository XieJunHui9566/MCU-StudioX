# 51 / 251 编译汇编

SDCC 8 位 8051 工程与 MX251 工程（包括 AI8051U 和 STC32G）成功编译后，点击源码工具栏“文件结构”右侧的“查看汇编”，在源码右侧打开“编译汇编”；悬停按钮会提示需要先成功编译。也可从“构建 → 查看编译汇编（51 / 251）”打开或关闭。编译完成只刷新已经打开的面板，不自动展开或重新打开已关闭的面板。无需连接下载器、写入固件或开启调试信息。

下拉框按源文件和产物类型选择，支持只读搜索、选择复制与原始清单切换：

- `.rst`：链接器生成的汇编清单，默认提取地址、机器码和指令。251 地址保持工具链的完整地址，不截断成 8051 的 16 位地址。
- `.asm`：编译器生成的汇编，保留符号、段、源注释等信息，属于链接前产物。
- `.lst`：汇编器生成的清单，地址属于链接前的编译单元，不能作为最终固件地址。

面板展示实际构建工具生成的文本，不把 8051 解码器套到 251 扩展指令上；按编译单元查看不等于完整固件反汇编，只有现存工具产物才列入选择器。SDK 与 IDE 的构建契约不变，IDE 不增加另一套编译规则。

成功构建凭据绑定汇编文件、源文件、工程设置、工具指纹与固件摘要。旧凭据未记录汇编时需重新编译；源码修改、失败或取消构建后不继续展示上次结果。SDCC 从当前 `compile_commands.json` 的实际输出定位对应清单，避免列出移除源码后残留的旧目标文件；MX251 使用本次 `latest` 与源码快照中的编译单元映射。同名源文件保留完整相对路径。

产物继续保存在既有构建目录；查看不会另建按时间或哈希累积的副本，不自动替换工具链或已安装 IDE。

离线验证入口：

```text
StudioX.StcValidation --assembly <runtime> <STC8.mcupack> <新输出目录> <MX251 SDK验证夹具目录>
MCU StudioX.exe --preview-build-assembly <新输出目录> <runtime> <已成功编译的51工程>
```

引擎验收使用真实 SDCC 与 MX251/CMake/Ninja；界面验收检查并排显示、只读状态、源码变化失效及深色、浅色、自定义强调色与较大 UI 字体。验证不连接硬件。
