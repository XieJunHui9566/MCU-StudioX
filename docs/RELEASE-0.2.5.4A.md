# MCU StudioX 0.2.5.4A

本次更新完善工程故障诊断、内置工具维护和帮助文档，并修复 ESP-IDF ESP32-S3 构建问题。产品版本为 **0.2.5.4A**，Windows 文件版本为 **0.2.5.4**。Windows x64 自包含安装包继续保留用户工程、偏好、草稿和已有插件，不修改系统 PATH。

## 工程健康检查与故障修复

从「工具」或「帮助」菜单打开工程健康检查。快速检查核对工程配置、器件包、开发环境组件版本、锁定依赖和构建缓存；深度检查进一步核对文件内容。快速检查不会冒充完整哈希校验。

发现问题后可进入开发环境组件、工程设置或对应帮助，导出保留原始诊断的 JSON 报告。针对过期的原生 CMake 缓存，先展示清理范围，再确认修复；源码、sdkconfig、固件、工具锁定及原始日志继续保留。构建和缓存修复使用共同占用保护。

## 开发环境组件管理

从「工具 → 开发环境组件 → 开发环境组件管理」查看各版本文件大小、已登记工程和器件包依赖、IDE 工具占用及内容校验状态。大小为逻辑文件大小；硬链接会影响实际磁盘占用，界面不承诺一定能释放的物理空间。

受校验的离线 `.studioxtools` 归档可以并存安装新版本；现有工程继续使用自己的版本锁，不自动迁移。旧版本先移到可恢复区域，可恢复或单独确认永久删除。正在使用、有依赖、当前最新版本或检查不完整时，清理入口会保护相关版本。其他工程可以手动登记，未登记的磁盘工程不在依赖扫描范围内。

## 帮助与程序员助手

帮助中心内置 32 篇文章，支持搜索、F1、深浅主题和紧凑窗口，覆盖新建工程、编辑、编译、下载、调试、串口、插件、Agent 和故障处理。

原「位运算实验室」更名为「程序员助手」：支持 8/16/32/64 位整数、AND/OR/XOR/NOT、移位、整数计算、二/八/十/十六进制转换、位域与大小端解释。插件 ID 保持 `studiox.bit-lab`，插件版本 1.0.2。本次 Release 单独提供插件文件；IDE 安装包不捆绑插件。

## ESP-IDF 修复

修复 ESP-IDF 5.5.4 / ESP32-S3 工程中，Windows 短路径把 Xtensa 编译器文件名变形，导致 `XTENSA_GNU_CONFIG` 与 `-dynconfig` 指向不同配置的错误。原生工具路径保留可执行文件原名；构建环境变化时重建受限的 CMake 缓存并保留源码与 sdkconfig。

## AG32 时钟与时序提示

引脚配置显示实际时钟与布局布线证据，针对 8 MHz 外部时钟、官方模拟 IP 提供已做离线回归的时钟推荐。下载前检查最新构建的建立/保持余量及凭据，过期或不完整证据不能作为下载依据。推荐频率不代表所有引脚组合或实物电路均通过时序；详细范围见 [AG32 外设说明](AG32_PERIPHERALS.md)。

## 发布与验证

GitHub Release 提供安装包、对应源码压缩包、独立程序员助手插件、SHA-256 和验证摘要。安装器沿用永久产品身份；可覆盖升级，同版本可修复，较新数字或字母修订版本均阻止降级。

本轮验证不连接或烧录硬件。构建、隔离安装和功能回归结果见附带的 `validation-summary.json`；既往实板验收范围以各型号文档为准。安装包未配置产品数字签名。

操作细节见 [工程健康检查](PROJECT_HEALTH.md)、[开发环境组件管理](TOOL_MANAGEMENT.md)、[帮助中心](USER_HELP.md)和 [插件](PLUGINS.md)。
