# MCU StudioX 0.2.4 预览版

本次发布 Windows x64 IDE 源码及同版本安装包。GitHub 仓库提供源码，安装包通过项目维护者的[百度网盘分享](https://pan.baidu.com/s/5fh5exaJIgC6ThwSS_IdDOA)下载。

## 更新

- 新增反汇编窗口，显示地址、机器码、指令、符号及真实 PC；支持跟随暂停/单步、浏览选中栈帧、手动地址。只读 MCP `debug_disassemble` 面向内置 Agent 和外部客户端使用。
- 新增 FreeRTOS 调试窗口和 `debug_rtos_snapshot`，读取任务、调度器、堆、队列/信号量/互斥量及可取得的栈余量。读取基于 ELF 调试信息和暂停目标内存，不调用目标函数；未知字段保持空值并提供诊断。
- 修复 WCH OpenOCD 已报告固件字节差异、MI 却仍返回 `done` 时的成功误判。烧录与附加要求实际完整映像校验输出；RTOS 读取拒绝严重矛盾的任务/调度器/堆数据。
- 器件包管理在新版同身份包完整覆盖旧版型号与模板、且校验通过时清理冗余版本；没有完整替代的旧版保留，已建工程的器件副本不随清理升级。
- WCH 包配方增加 CH32V307、CH32V203 V20x 分支及 CH592 的官方 FreeRTOS 模板，保留来源、SHA-256 和许可。CH32V203CCT6、CH595 的专用移植未核实，继续提供裸机模板。器件包版本和源码版本分别管理，配方更新不代表公开包仓库已同步全部包。
- 删除已无引用的主题处理方法、旧 F407 单型号时钟/调试素材及被现行生成器替代的脚本。开发验证复用已有工具链，清理生成工程及重复副本；此项不表示 IDE 自动删除用户工程。

0.2.3 已提供的 AI 对话、运行中追加提示、真实 API 缓存用量、网络/PDF/QMD、MCU Skill、工程与设备 MCP、Git 图谱及手动在线包同步继续保留。

## 验证

2026-09-26 已完成两套实板 MCP RTOS 观测：

| 板卡 / 探针 | 已验证范围 |
| --- | --- |
| STM32F407ZG / ST-Link，FreeRTOS V10.3.1 | 三项任务状态、32 KiB `heap_4`（空闲 22520 字节）、注册队列 TmrQ、继续/暂停后的 Tick 变化 |
| CH32V307VCT6 / WCH-LinkE，FreeRTOS V10.4.6 | 7984 字节独立验收固件的下载及完整映像校验；三项任务、栈余量、12 KiB `heap_4`（空闲 9856 字节）、队列、二值/计数信号量、未持有的普通/递归互斥量 |

两套观测均确认退出后恢复目标运行及探针释放。以上是既有实板验收结果，制作源码发布时没有再次连接硬件；它们不代表其它型号、所有 FreeRTOS 版本或全部调试场景已验证。详细数值及缺失字段见 [FreeRTOS 调试与实板范围](RTOS_DEBUGGING.md)。

近期 RTOS 相关离线回归包含内核 25 项、映像输出 12 项、辅助程序 8 项，共 45 项通过；对应产品构建零警告、零错误。离线数据及演示截图不能代替实板观测。持有互斥量、递归加锁、优先级继承、争用、堆碎片变化、持续调度性能和 SMP 尚未实板验证。

## 发布范围

源码仓库包含 IDE 源码、维护配方、离线验证工具和许可材料。用户工程、API 密钥、账号凭据、对话历史、原理图、原始硬件日志、Flash 备份、构建缓存、工具链及器件包二进制不纳入本次源码发布。README 的运行截图沿用已有版本并标明拍摄范围，没有把旧截图作为新功能的硬件证明。
