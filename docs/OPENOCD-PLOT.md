# OpenOCD 变量绘图

入口为 **调试 → OpenOCD 变量绘图**。通过 IDE 当前调试会话拥有的 OpenOCD 读取 SRAM，固件无需使用串口、RTT 或专门的输出代码。该功能属于通用调试能力，不绑定某一芯片系列。

## 操作

1. 打开具有 OpenOCD 源码调试支持的工程，编译并使用已匹配的板上固件，点击 IDE 的「调试」。现有调试流程会暂停目标并校验板上程序与本次 ELF，调试按钮不会自动下载。
2. 目标暂停时，打开绘图页并添加全局变量，如 `app_counter`、`sensor.value`、`samples[0]`。地址和类型取自当前 ELF。最多 8 通道，支持 8/16/32 位有符号/无符号整数、float、double 和 bool；自定义别名不能识别时可以选择与存储大小一致的类型。
3. 设置采样间隔（20–10000 ms，默认 100 ms），点击「开始采集」，再点击调试工具栏的「运行」。采集不会自动运行或暂停程序，暂停时采样标记为静态值。
4. 曲线可拖动、滚轮平移、Ctrl+滚轮缩放时间、Ctrl+Shift+滚轮缩放数值，双击或「恢复视图」恢复跟随和自动 Y。表格列出通道颜色、地址、类型和最新值。
5. 「停止采集」保留曲线并保持目标原状态。导出 CSV 包含变量名/地址/类型、主机读回时间、单调经过时间、运行状态、曲线分段以及丢失统计。关闭绘图标签会停止采集；结束调试立即取消后续采集。重新连接或切换工程后需要清空通道并重新解析变量，不复用旧地址。

添加、移除通道或重新开始采集会清空旧曲线；需要保留时先导出 CSV。最多保留最近 10000 组，超限淘汰最旧记录并显示计数。

## 适用范围与数据含义

- 只接受当前器件包声明的主 SRAM 中的全局标量、成员和固定数组元素。拒绝局部变量、寄存器、指针/引用链、越界数组元素、函数调用、赋值及外设寄存器轮询。暂不解析文件限定静态符号、C++ 命名空间或额外 RAM 区。
- **运行中读内存依赖目标调试硬件、OpenOCD 版本和探针支持。** 支持源码调试不等同于已验证运行中采样。读取被拒绝、断开或超时即停止采集，并保留原始诊断；不会通过循环 halt/resume 模拟实时采样。
- 时间轴是主机读回时间，不能当作 MCU 内部的精确采样时间。数据通过 Tcl 内存读取按通道顺序取得，多字节和多变量不保证原子快照；高速变化时可能读到更新中的组合值。它适合低频趋势监控，不替代示波器、逻辑分析仪或固件内同步采样。
- 实际速度受 USB、探针、目标和通道数限制。读取超出周期时统计错过的周期并断开曲线段，不积压请求或补出假数据。NaN/Infinity 计入无效数值并形成缺口。
- 变量须在 ELF 中保留符号和存储位置；优化掉的变量不可采集。目标尚未初始化的 SRAM 读数不代表有效应用值。采样无需修改固件，但调试探针访问可能占用总线带宽。

## 实现与验证

`DebugSessionService` 仍是调试目标的唯一所有者；采样与调试动作通过同一应用服务门锁串行协调。复用现有 OpenOCD 子进程及 ProbeLease，新增仅绑定 127.0.0.1 的动态 Tcl 端口，确认本次进程监听后才连接。Tcl 客户端仅暴露读内存，响应以 0x1a 分帧，单次最多 8 字节，超时或取消后关闭通道，避免迟到帧污染下一次读取。没有第二个探针连接，也不向 Desktop 暴露原始 Tcl 命令。

协议依据：[OpenOCD Tcl RPC](https://openocd.org/doc/html/Tcl-Scripting-API.html) 与 [目标内存命令](https://openocd.org/doc/html/CPU-Configuration.html)。使用 target 的 `mem2array` 兼容内置厂商旧版。主机按 ELF 字节序解码。

离线检查：`dotnet run --project tools/StudioX.OpenOcdPlotChecks -c Release`。覆盖符号/类型/边界、TCP 分帧/取消、采样生命周期、迟到响应、数值与 CSV、缓冲/周期统计；不连接探针。

可加 `-- --runtime <IDE runtime 目录>`，对 ARM、AG32、WCH 三套已有 OpenOCD 运行 `noinit` 的 Tcl RPC 检查。只使用测试 proc 提供的模拟内存，不初始化探针或目标。2026-09-29 本地结果：52 项采样/协议检查、20 项 WPF 界面检查和 33 项既有调试回归检查通过；完整构建 0 警告、0 错误。另以实际 ARM GCC/GDB 编译 ELF 并验证全局变量、成员、数组的地址/类型解析。报告及截图保存在 `artifacts/validation/openocd-plot-20260929`，临时工程和隔离用户数据已清理。

界面检查：`MCU StudioX.exe --preview-openocd-plot <输出目录>`，使用隔离用户数据和明确标记的模拟信号，检查真实按钮、停止、错误、缩放及深/浅色和小窗口截图。它不代表实板采样验收；各目标的运行中内存访问仍须按实际芯片和探针进行独立验证。
