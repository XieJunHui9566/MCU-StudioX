# MCU StudioX 0.2.2 预览版

此版本修复 Windows 升级安装后桌面和开始菜单快捷方式继续显示旧图标的问题。程序仍使用 0.2.1 已确定的黑金色 SX 图标。

安装器现在为快捷方式安装一个随版本命名的独立 `.ico` 文件，并明确指定快捷方式的图标路径，避免 Windows 沿用同一 EXE 路径的旧图标缓存。

运行 `MCU-StudioX-0.2.2-win-x64-Setup.exe` 可在原目录覆盖升级。安装前请保存工程并关闭 IDE。器件支持与分发限制延续 [0.2.1 发行说明](RELEASE-0.2.1.md)及[安装器说明](INSTALLER.md)。
