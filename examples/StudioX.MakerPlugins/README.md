# StudioX 创客插件 · 1.0.0

四个独立 `.studioxplugin` 包，可单独导入/启用。入口与矢量图标由各自清单声明；新增这些插件无需改动或重新编译 IDE。使用 API 2、.NET 10 独立宿主和既有声明式控件，不安装全局环境。无文件、网络或设备操作；结果由用户复制到工程。无需安装第一批实验室插件。

| 插件 | 功能 |
|---|---|
| RGB 灯效工坊 `studiox.rgb-studio` | 彩虹循环、双色渐变、单色呼吸；亮度指数、RGB/GRB 帧表、RGB565 数值；三路亮度曲线 |
| 蜂鸣器旋律工坊 `studiox.melody-studio` | 音符/升降号/休止符、BPM、发声比例；音高时间线与 PWM 播放表 |
| PID 调参沙盒 `studiox.pid-studio` | 五页调参流程、双对象模型、限幅、抗积分饱和、微分滤波、延迟、扰动、噪声、基线比较、指标及 C99 控制器 |
| 按键消抖实验室 `studiox.debounce-studio` | 电平变化序列、稳定计时/饱和增减计数、阶梯图与确认事件、无阻塞 C 状态机 |

## 导入与使用

打开一个工程，在插件管理页导入所需 `.studioxplugin` 并启用，点击左侧相应图标。每个包可单独禁用和卸载。支持通用活动栏接口的本机构建可显示独立图标；早期 0.2.5.3 宿主仍可在插件管理页显示面板。

修改参数后点击计算/生成。输入错误会保留上次成功结果。复制框点入后 Ctrl+A / Ctrl+C。不自动写入工程，也不初始化定时器、GPIO、PWM 或执行硬件输出。

## PID：从试验到 C 代码

1. **PID 参数**：Kp、Ki、Kd、微分滤波时间常数、抗积分饱和开关；可载入平稳、二阶振荡、积分饱和、负载扰动、噪声五种预设。
2. **对象与采样**：一阶 `K/(τs+1)` 或同 τ 二阶串联 `K/(τs+1)²`、执行器纯延迟、目标、采样周期、试验时长。
3. **限幅与扰动**：执行器上下限、输入负载阶跃、开始时间、传感器均匀噪声。
4. **曲线与指标**：响应/误差/控制量、P/I/D、真实值/测量值；将一次试验记为基线再改参数比较。不同试验条件会明确标记。曲线为独立自动纵轴，数值比较以指标表为准。
5. **代码与数据**：C99 控制器以及最多 40 行 CSV 摘要。Agent 的 `simulate` 分页返回完整采样（最多 5001 点）；`offset` 默认 0、`limit` 默认 1000，使用相同模型参数和返回的 `nextOffset` 继续读取，末页返回 null。参数决定结果，固定噪声种子保证各页一致；分页遵守既有宿主消息限制。

切换页面会保存当前参数。保存不自动运行；未重新仿真时提示结果仍属于上次试验。导出与基线始终关联已完成的参数快照。Agent 的独立仿真不会覆盖面板里未完成的调参。

### 控制器与数值口径

- 并联位置式 PID：`e=r-y_measured`，`P=Kp·e`，积分候选 `I+Ki·Ts·e`。Ki、Kd 使用秒为时间单位。
- 微分作用于测量：`D=-Kd·d_filtered`。后向欧拉一阶滤波系数 `Ts/(Tf+Ts)`；Tf=0 时不滤波。首个采样将前值设为当前测量，避免启动微分冲击。
- 抗饱和采用条件积分：如果候选输出超过上限且误差为正，或低于下限且误差为负，拒绝本步积分增量；否则接受。最终输出始终限幅。反向误差可以帮助退饱和。关闭该开关可观察 windup。
- 对象采用零阶保持下的解析离散递推；二阶为两个惯性环节串联。纯延迟四舍五入到整数采样周期，界面显示实际值。扰动时间向上对齐采样网格，负载在延迟之后、对象增益之前加入。没有摩擦、死区、非线性和真实器件辨识。
- 传感器噪声为固定 xorshift32 种子 `0x12345678` 的均匀噪声，便于复现实验。噪声不直接改变对象状态；指标使用真实输出。
- 初始状态为零，t=0 施加正目标阶跃。上升时间采用目标幅值的 10%→90%，线性插值；超调相对目标计算。稳定时间使用 ±2% 目标幅度带，且尾部必须再观察 `max(0.5s,5Ts)`。这是有限观察窗口内的结果，不证明永久稳定。
- 有负载扰动时，阶跃指标仅统计到扰动发生前；恢复时间从扰动发生算起。未达到或观察不足返回 null，界面显示“未确认 / 不适用”。“末段误差”明确为试验最后 10% 的平均误差，未声称一定达到稳态。
- IAE/ISE 使用全程梯形积分；限幅占比按控制采样次数统计。末点绘制最后输出值，不额外运行控制器。长曲线分桶保留局部极值，指标仍用全部采样。
- C 输出使用 float，沙盒使用 double；验证在代表性输入上比较允许的浮点误差。C 使用独立状态结构，调用者负责固定周期、量纲换算和并发保护；参数适用于该离线模型，不代表实板调参完成。

参考方法：[MathWorks 并联 PID](https://www.mathworks.com/help/control/ref/pid.html)、[离散 PID 与抗积分饱和](https://www.mathworks.com/help/simulink/slref/discretepidcontroller.html)、[阶跃指标定义](https://www.mathworks.com/help/control/ref/dynamicsystem.stepinfo.html)。本插件未依赖 MATLAB/Simulink，也不声明数值实现与它们逐位一致。

## 其它插件的输入规则

- RGB：2–32 帧。输出 `round(255 × brightness × component^gamma)`；彩虹与呼吸不重复周期终点，渐变包含两端。RGB565 按 R5:G6:B5 截取高位，是 16 位数值，传输字节序由驱动决定。曲线展示亮度代码，不模拟屏幕或 LED 的实测颜色。
- 旋律：1–48 个音符，格式 `C4:1 F#4:0.5 Bb3:2 R:0.25`；八度 0–8，每音 0.125–8 拍。十二平均律 A4=440Hz，整数 Hz 输出；累计节拍边界取整至毫秒，避免逐音累积舍入误差。面板不播放声音。
- 消抖：1–32 个严格递增的 `ms:0/1` 变化，首项 0ms。稳定计时从检测到变化开始等待完整阈值；增减计数在变化当次就计数，两者延迟口径不同。初始化直接接受当前电平，不产生按下事件。短于采样周期的脉冲可能漏检。

## 独立构建

在仓库根目录运行：

```powershell
./tools/Build-MakerPlugins.ps1 -OutputDirectory ./artifacts/maker-build-new `
  -PackagingCli <已有且支持活动栏声明的StudioX.Cli.dll>
```

只编译插件和 SDK 契约；复用既有打包 CLI，不重新编译 IDE。脚本要求新输出目录，生成四个归档、SHA256SUMS 与合集 ZIP。每个包仅包含自己的插件程序集、文档、清单；不捆绑 IDE 核心或 SDK 的运行时副本。
