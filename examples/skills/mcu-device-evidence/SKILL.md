# MCU 器件资料核验

适用于选型、工程创建、启动文件、时钟、内存布局、下载探针或框架可用性问题。

1. 从用户或 `project_info` 取得完整料号。料号不完整或同名容量不同的情况下，先请用户明确型号；不要补猜后缀。
2. 用 `device_search` 查候选，再以准确 ID 调用 `device_info`。多个包提供同一型号时，明确指定包 ID 与版本。需要工程模板时调用 `device_templates`。
3. 以器件包明确声明的架构、Flash/RAM、工具链、CPU 标志、探针和模板作答。区分“包已安装并核验”“离线编译验证”“实板验证”三种证据，不把一种说成另一种。
4. 对于包未覆盖的寄存器、引脚、时钟或勘误，先查厂商发布的准确型号数据手册/参考手册，并标明文档名称与版本。当前 `microchip_*` 工具只覆盖 Microchip 产品，不能用其结果替代其他厂商的资料。
5. 若没有足够证据，列出待确认的具体字段与来源；不要按相邻型号、常见容量或网上示例自行补全。

此技能只指导资料核验，不授权下载 SDK、修改工程、连接设备或烧录固件。上述操作仍按用户请求和 StudioX MCP 逐次授权执行。
