# 外观工作室插件

应用级 `.studioxplugin`，无需打开工程。支持日奈紫夜、日奈月白、日奈暮光三套氛围环境，六组基础配色、内置深浅主题及界面/代码字体设置。按用户要求，主题只包含空校园、紫色光环与暮光环境，不包含人物或樱花场景。

从插件管理页导入并启用，点击左侧“外观”入口。选择设置后，下方面板先显示局部预览；点击“应用外观”才保存并更改工作台。“恢复默认配色与字体”只重置待应用的选择，仍需点击应用。禁用或卸载插件不撤销已保存外观。

主题、字体与动态壁纸独立：不会清除壁纸文件、暂停/重载视频、改写透明度/调暗/模糊、最小化及失焦暂停规则或编辑器柔光偏好。

“显示氛围背景”可单独关闭环境，强度可设为 0–100%。没有壁纸时使用完整环境；有图片或视频壁纸时，环境强度自动按 30% 叠加，继续尊重不透明工作区。预览不改写全局偏好；应用后将校验过的 PNG 副本存入用户 `theme-artwork` 目录，插件禁用后仍可恢复。

需要支持外观目录格式 2 和主题环境资源的本轮 StudioX 宿主源码构建。早期纯色/字体版宿主会拒绝格式 2，仅导入新版插件不足以提供氛围功能。IDE 产品版本仍为 `0.2.6.14`，插件内容升级为 `1.1.0`，可以由插件管理器正常升级。

构建：`tools/Build-AppearancePlugin.ps1 -OutputDirectory <不存在的输出目录>`。归档包含插件 DLL、PNG、素材说明与提示词，SDK 契约由独立宿主提供。完整索引覆盖全部资源；拒绝远程图片、XAML、未索引图片、路径穿越、哈希不一致和过大 PNG。

`assets/hina-environment.png` 是内置 imagegen 工具生成的氛围素材，不是游戏官方素材；生成提示词和来源声明见同目录文本文件。
