# StudioX 实验室插件

四个独立的 API 2 插件，使用 C# / .NET 10 与 StudioX SDK。程序员助手的本地更新包为 1.0.4，其余插件版本保持不变；IDE 产品版本不变。它们不依赖特定 MCU，不访问网络、文件或设备，不修改系统 PATH；计算结果可复制使用。每个归档单独导入、启用和停用。

| 插件 | 用法 |
| --- | --- |
| 程序员助手 | 8/16/32/64 位，HEX/DEC/OCT/BIN 同时转换；AND/OR/XOR/NOT/NAND/NOR、左右移位、循环移位、整数四则和取余、括号表达式；支持有符号解释、连续计算、清空。另有位域页，保留查看/置位/清零/翻转/替换及大小端字节。输入错误保留上次成功结果。 |
| 协议校验助手 | 输入 HEX 或 UTF-8 文本（1–512 字节），查看 CRC-16/MODBUS、CRC-16/IBM-3740（CCITT-FALSE）、CRC-32/ISO-HDLC、SUM8、XOR8、LRC8。HEX 可用空白、逗号、分号或 `0x` 前缀，也接受连续双位字节。所有输入字节均参加计算，已有校验尾字节须先移除。 |
| 波形实验室 | 选择正弦、三角、锯齿或 PWM，生成一个周期 8–256 个 `uint16_t` 采样点，显示目标更新率。PWM 高电平点数按四舍五入量化，显示实际占空比。采样点之间的绘图连线不表示真实输出斜坡。 |
| 像素图案工坊 | 选择爱心、笑脸、小怪兽，或输入以 `/` 分隔的等宽 0/1 行，宽高均为 1–32。支持水平翻转、反色、逐行 MSB 和纵向 8 行页 LSB 打包；不足一字节的有效区外始终补 0。 |

打开任意工程，在「扩展」中导入 `.studioxplugin` 并启用，左侧竖栏显示插件自己的图标。程序员助手 1.0.4 点击后打开独立计算器窗口，重复打开复用该窗口，关闭窗口保留本次会话状态；其余三个插件保留标签页。停用、崩溃或关闭工程会关闭相应窗口并移除入口。新版程序员助手需要同时具备 `panelWindows` 和 `programmerCalculator` 能力的 IDE 构建，旧安装版不能仅靠导入新插件获得该界面。

计算器采用 Windows 程序员计算器式布局，提供 A–F 与数字键盘、四进制读数、BYTE/WORD/DWORD/QWORD、符号切换、逐位翻转、大小端字节和 C 定宽常量。输入会在短暂合并后自动更新进制与完整表达式结果，并保留光标；移位和循环移位键立即执行一位，无需等号。按 = 或 Enter 可显式提交，Esc/CE/清空立即归零，支持粘贴表达式。切换进制保持数值，主动缩窄位宽保留低位；输入越界仍报错。深浅配色随 IDE 切换，窄窗口会将 MCU 工具移到键盘下方，使用滚动区访问。复制区域只读，计算表达式可编辑。

结果框可点入后按 Ctrl+A / Ctrl+C 复制。结果框是复制区，手动编辑它不会改变计算参数，也不会写入工程。输入错误会显示中文说明并保留上次正确结果。四个插件也各自提供一个 `calculate` Agent 工具，使用相同算法和边界校验；参数省略时使用初始示例值。

波形为离线计算，不接硬件。点阵扫描方向、寄存器位域语义、实际定时器和 DAC 更新率均由目标工程决定。插件不自动生成外设初始化代码。

CRC 参数和 `123456789` 检查值核对自维护者发布的 [CRC RevEng 16 位目录](https://reveng.sourceforge.io/crc-catalogue/16.htm) 与 [32 位目录](https://reveng.sourceforge.io/crc-catalogue/17plus.htm)；实现为本项目独立的逐位算法。MODBUS / IBM-3740 / ISO-HDLC 检查值分别为 `4B37` / `29B1` / `CBF43926`。无外部 SDK 或第三方算法源码随包交付。

四个插件的入口名称和矢量图标都在本目录 `manifests/*.json` 的 `activity` 中声明。独立窗口与程序员计算器属于宿主认可的声明式呈现能力，不按插件 ID 分支；宿主只呈现和提交输入，整数算法仍在插件进程。使用已有能力的后续插件可自行声明名称、图案、面板和命令，无须重新编译 IDE；新增宿主控件类型需要更新 IDE。

从源码构建：`tools/Build-LabPlugins.ps1 -OutputDirectory <新的输出目录> -PackagingCli <支持 activity 的 StudioX.Cli.dll 或 exe>`。此方式只编译插件；省略 `PackagingCli` 会先构建本仓库的通用打包工具。两种方式都不构建 Desktop、不修改 IDE 产品版本、不制作安装包。
