# SharpCompress

MCU StudioX uses SharpCompress 0.50.3 for managed 7z/LZMA2 development component import and export.
Both full and light IDE distributions include this dependency; no system-wide 7-Zip installation is required.

- Project and corresponding source: https://github.com/adamhathcock/sharpcompress/tree/0.50.3
- NuGet: https://www.nuget.org/packages/SharpCompress/0.50.3
- License: MIT; see `SharpCompress-MIT.txt`.

Release authoring scripts may use a developer's separately installed 7-Zip. Its executable is not bundled with MCU StudioX.
